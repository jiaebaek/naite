# 16 · 앱 지인 테스트 계획 (컨시어지 대체 · 활성화 검증)

> **용도.** 리디자인(통찰-먼저·성장좌표·lean·전문가기준)이 **지난 테스트 실패**를 고쳤는지 반증 가능한 게이트로 검증. 컨시어지 MVP 대신, 실제 앱을 지인에게 쥐어주고 관찰.
> **전제:** [00-전략-원칙.md](00-전략-원칙.md)(SSOT §2 신뢰·§8 사업성). 지난 실패 = [13-사용자-피드백-통찰.md](13-사용자-피드백-통찰.md)("복잡·어렵다 / 공교육이라 전문성 없어보임 / 할일앱 / 입력 귀찮 / 세부 많음").
> **성격:** 정량 통계 아님. n=5~8 질적 검증 — **패턴이 반복되면 신호.** 목표는 "고쳤나 / 못 고쳤나"를 정직하게 보는 것.

---

## 0. 이번 테스트가 답할 질문 하나
> **"입력 없이 첫 화면만으로, 이게 '할 일 앱'이 아니라 '우리 아이 성장 지도'로 읽히고, 안심이 되는가?"**
나머지는 부차. 이게 무너지면 뒤는 볼 필요 없음.

---

## 1. 가설 · 게이트 (반증 가능)

| # | 가설(리디자인이 건 베팅) | 관찰 지표 | 통과선(n=6 기준) | 실패 시 함의 |
|---|---|---|---|---|
| **H1 · 안도** | 나이+유치원만으로 첫 화면이 안심을 준다 | 첫 화면 30초 무프롬프트 반응의 **감정 톤** | 과반이 안도/긍정("잘 하고 있네/괜찮네"), 불안·무감 아님 | 안도 엔진 실패 → 히어로 카피·구성 재설계 |
| **H2 · 정체성** | 할일앱 아니라 성장 지도로 읽힌다 | "이게 뭐 하는 앱?" 한 문장 자발 서술 | 과반이 **지도/상태/우리 아이** 언어. "할일/체크리스트" 아님 | 여전히 할일앱 → 메인 IA·레인 표현 재작업 |
| **H3 · 신뢰** | 전문가 기준·강점먼저가 전문성으로 읽힌다 | "믿을 만해 보여?" + 무프롬프트 신뢰 언급 | 과반 "믿을만/근거 있어 보임". "전문성 없어 보임" 재발 안 함 | 신뢰 실패 → 사람-권위(교사 자문) 승격 필요(§대기) |
| **H4 · 노력>가치 역전 해소** | 입력 0~1개로도 가치가 있다 | 온보딩 완료 후 **입력 없이** 유용성 인식 | 과반이 입력 강요 없이 "쓸만/보임". "입력 귀찮/내가 다 연결?" 재발 안 함 | 통찰-먼저 실패 → auto-cover 확대·입력 더 뒤로 |
| **H5 · 복잡성** | lean·강점먼저로 "한눈에" 파악된다 | 첫 화면에서 길 잃음/스크롤 헤맴/"복잡" 언급 | "복잡·어렵다" 재발 과반 이하 · 주요 태스크 막힘 0~1 | 여전히 복잡 → 영역탭·상세 더 접기 |
| **H6 · 재방문 의향**(약) | 성장좌표·재방문델타가 다시 열게 한다 | "또 열어볼 것 같아? 언제?" | 과반이 구체적 재방문 계기 말함 | 리텐션 훅 약함 → 델타·관찰체크 강화 |
| **H7 · 리퍼럴**(약) | 공유 카드를 지인에게 보내고 싶다 | 공유카드 보고 "보낼 것 같아?" | 소수라도 진짜 "보낼 듯"(예의성 제외) | 리퍼럴 훅 재설계 |

- **핵심 게이트 = H1·H2·H3.** 이 셋 통과 못 하면 H4~H7 결과와 무관하게 **재수정 후 재테스트.**
- H6·H7은 의향(proxy)일 뿐 — 실제 리텐션/리퍼럴은 배포 후. 과신 금지(정직=겸손).

## 2. 대상 (지인 리크루팅)

- **n = 5~8**, 미취학~초2 자녀 부모. (지난 채널: 춘천 지인·카페.)
- **다양성 확보**(패턴 신뢰도↑): 워킹맘 ↔ 주양육 아빠 / 유치원 ↔ 초1~2 / 사교육 많음 ↔ 없음 / 교육 불안 높음 ↔ 낮음.
- 지난 인터뷰이(4명)와 **가급적 다른 사람** — 재설계 효과를 새 눈으로.

---

## 3. 진행 프로토콜 (1인 15~20분)

편향 방지가 생명. **기능 설명 먼저 하지 말 것. "좋지?" 유도 금지. 가능하면 내가 만들었다고 먼저 말하지 말 것.**

1. **사전 1문(30초):** "요즘 아이 교육에서 제일 신경 쓰이는 게 뭐야?" (맥락·기대선 확보)
2. **무프롬프트 첫인상(H1·H2):** 앱 열어 건네고 *"떠오르는 대로 말해줘."* → **30초 개입 없이 관찰.** 첫 감정어·첫 해석을 그대로 받아적기.
3. **정체성 질문(H2):** "이거 뭐 하는 앱 같아? 한 문장으로." *(설명 듣기 전에 물어야 함)*
4. **온보딩 태스크(H4):** "너희 아이로 한번 맞춰볼래?" → **탭 수·막힌 지점·포기 여부** 기록. 입력 강요 안 하는지 관찰.
5. **자유 탐색 3분(H5):** 헤매는 지점·"복잡" 발화·안 눌러본 영역 관찰.
6. **신뢰 질문(H3):** "이 앱, 믿을 만해 보여? 왜?"
7. **공유 카드(H7):** 카드 보여주고 "이거 지인한테 보낼 것 같아?"
8. **마무리(H6):** "또 열어볼 것 같아? 언제?" → "안 쓸 것 같으면 솔직히 왜?"

## 4. 기록 템플릿 (1인 1장)

```
대상: (관계/자녀 나이·유치원or초/사교육 유무/교육불안 상하)
사전 신경쓰임:
[H1] 첫 30초 감정어(원문):            → 안도/불안/무감
[H2] "뭐 하는 앱?" 원문:              → 지도언어 / 할일언어

[H5] 헤맨 지점 / "복잡" 발화:
[H3] 신뢰 원문:                        → 믿을만/의심(전문성없음 재발?)
[H7] 공유 의향 원문:
```

## 5. 판정 (테스트 후)

- **Go(구현 검증·배포 준비):** 핵심 게이트 **H1·H2·H3 모두 통과** + H4·H5 실패 재발 없음.
- **수정 후 재테스트:** 핵심 게이트 중 하나라도 미달 → 원인 영역만 고쳐 같은 프로토콜 재실행.
- **더 깊은 피벗 신호:** H2(정체성)가 또 "할일앱"이거나 H3가 또 "전문성 없음"이면 → 표현 손질 넘어 **모델/권위 구조**(교사 자문 승격 §대기) 재검토.

> 판정은 **인용 기반**으로. "느낌상 좋았다" 금지 — 템플릿의 원문 발화로 게이트를 매김(정직).

## 6. 이 테스트로 안 볼 것 (경계)
- 가격 지불의향 정밀 측정 — 지금 아님(코어 검증 먼저, SSOT §8). 마무리에서 자발적으로 나오면 메모만.
- 실제 리텐션/리퍼럴 수치 — 배포 후 정량.
- 학원 견적·Pull B2B2C — 코어 검증 후 fast-follow(09 로드맵).
