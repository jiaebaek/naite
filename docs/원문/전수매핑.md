# 교육과정 전수 매핑 — 우리 Domain이 원문을 얼마나 덮는가

> 작성 2026-08-22. 계기: *"교육과정 원문에 있는 모든 영역들에 대해서 전부 다뤄야 할 것 같아.
> 예체능이나 과학같은 분야는 안 들어가 있잖아. 문서에 있는 모든 영역들에 대해서 확인한 거야?"*
>
> **답: 확인하지 않았다.** 필요하다고 생각한 것만 골라 넣었다.
> P-6("모든 영역에서 다 하고 있는지 확인")은 **영역 목록 자체가 완전해야** 성립한다.

## 1. 취학 전 — 2019 개정 누리과정

**5개 영역 × 3개 내용범주 = 15개 내용범주, 총 59개 내용**

| 영역 | 내용범주 | 내용 수 | 현재 반영 |
|---|---|---|---|
| **신체운동·건강** | 신체활동 즐기기 | 4 | △ 1개만 |
| | 건강하게 생활하기 | 4 | △ 1개만 |
| | **안전하게 생활하기** | 4 | ❌ **0개** |
| **의사소통** | **듣기와 말하기** | 6 | ❌ **0개** |
| | 읽기와 쓰기에 관심 가지기 | 3 | ✅ 2개 |
| | 책과 이야기 즐기기 | 3 | △ 1개만 |
| **사회관계** | 나를 알고 존중하기 | 3 | ✅ 2개 |
| | 더불어 생활하기 | 6 | △ 2개만 |
| | **사회에 관심 가지기** | 3 | ❌ **0개** |
| **예술경험** | 아름다움 찾아보기 | 2 | △ 1개만 |
| | 창의적으로 표현하기 | 5 | △ 3개만 |
| | 예술 감상하기 | 3 | △ 1개만 |
| **자연탐구** | **탐구과정 즐기기** | 3 | ❌ **0개** |
| | 생활 속에서 탐구하기 | 7 | △ 4개만 |
| | **자연과 더불어 살기** | 3 | ❌ **0개** |

**59개 중 19개(32%)만 반영. 내용범주 15개 중 5개는 통째로 누락.**

### 누락된 내용범주 원문

**자연탐구 · 탐구과정 즐기기** — 목표: 일상에서 호기심을 가지고 탐구하는 과정을 즐긴다.
- 주변 세계와 자연에 대해 지속적으로 호기심을 가진다.
- 궁금한 것을 탐구하는 과정에 즐겁게 참여한다.
- 탐구과정에서 서로 다른 생각에 관심을 가진다.

**자연탐구 · 자연과 더불어 살기** — 목표: 생명과 자연을 존중한다.
- 주변의 동식물에 관심을 가진다.
- 생명과 자연환경을 소중히 여긴다.
- 날씨와 계절의 변화를 생활과 관련짓는다.

> **이 둘이 "과학"이다.** 누리과정에서 자연탐구는 수학만이 아니라 과학을 포함한다.
> 우리는 `생활 속에서 탐구하기`의 수학적 부분만 떼어 `수학` Domain에 넣고 나머지를 버렸다.

**신체운동·건강 · 안전하게 생활하기** — 목표: 안전한 생활습관을 기른다.
- 일상에서 안전하게 놀이하고 생활한다.
- TV, 컴퓨터, 스마트폰 등을 바르게 사용한다.
- 교통안전 규칙을 지킨다.
- 안전사고, 화재, 재난, 학대, 유괴 등에 대처하는 방법을 경험한다.

**사회관계 · 사회에 관심 가지기**
- 내가 살고 있는 곳에 대해 궁금한 것을 알아본다.
- 우리나라에 대해 자부심을 가진다.
- 다른 나라의 다양한 문화에 관심을 가지고 존중한다.

**의사소통 · 듣기와 말하기** (6개) — 원문은 [누리과정_취학전.md](누리과정_취학전.md) 참조

## 2. 초1~2학년군 — 2022 개정 교육과정

**총 100개 성취기준. 이것이 전부다.**
(영어·과학·사회·음악·미술·체육 교과는 **초3부터**다. 1~2학년에는 없다.)

| 교과 | 성취기준 수 | 현재 반영 |
|---|---|---|
| 국어 | 23 | △ 4개 |
| 수학 | 29 | △ 4개 |
| 즐거운 생활 | 16 | △ 3개 |
| **바른 생활** | 16 | ❌ **0개** |
| **슬기로운 생활** | 16 | ❌ **0개** |

**100개 중 11개(11%)만 반영. 교과 5개 중 2개는 통째로 누락.**

### 바른 생활 (16개) — 인성·공동체·생활습관

- **[2바01-01]** 학교 생활 습관과 학습 습관을 형성하여 안전하고 건강하게 생활한다.
- **[2바01-02]** 나를 이해하고 존중하며 생활한다.
- **[2바01-03]** 가족이나 주변 사람을 배려하며 관계를 맺는다.
- **[2바01-04]** 생태환경에서 더불어 살기 위해 노력한다.
- **[2바02-01]** 공동체에서 내가 할 수 있는 일을 찾아보고 실천한다.
- **[2바02-02]** 우리나라의 소중함을 알고 사랑하는 마음을 기른다.
- **[2바02-03]** 차이나 다양성을 서로 존중하면서 생활한다.
- **[2바02-04]** 새로운 활동에 호기심을 갖고 도전한다.
- **[2바03-01]** 하루의 가치를 느끼며 지금을 소중히 여긴다.
- **[2바03-02]** 계절의 변화에 대응하며 생활한다.
- **[2바03-03]** 여러 인물의 삶을 통해 공동체성을 기른다.
- **[2바03-04]** 공동체 속에서 지속가능성을 위한 삶의 방식을 찾아 실천한다.
- **[2바04-01]** 모두를 위한 생활환경을 만드는 데 참여한다.
- **[2바04-02]** 다양한 생각이나 의견에 대해 개방적인 태도를 형성한다.
- **[2바04-03]** 여럿이 하는 활동에 관심을 갖고 자발적으로 협력한다.
- **[2바04-04]** 지금까지의 생활 습관과 학습 습관을 되돌아본다.

> **[2바01-01]** 이 하나가 우리가 "학교적응"이라 부르던 것의 정식 근거다.

### 슬기로운 생활 (16개) — 탐구 (사회 + 과학의 기초)

- **[2슬01-01]** 학교 안팎의 모습과 생활을 탐색하며 안전한 학교 생활을 한다.
- **[2슬01-02]** 나를 탐색하여 나에 대해 설명한다.
- **[2슬01-03]** 가족이나 주변 사람에게 관심을 갖고 함께 살아가는 모습을 탐구한다.
- **[2슬01-04]** 사람과 자연, 동식물이 어우러져 사는 생태를 탐구한다.
- **[2슬02-01]** 우리가 살고 있는 마을과 사람들이 생활하는 모습을 살펴본다.
- **[2슬02-02]** 우리나라의 모습이나 문화를 조사한다.
- **[2슬02-03]** 알고 싶은 나라를 탐구하며 다른 나라에 관심을 갖는다.
- **[2슬02-04]** 궁금한 세계를 다양한 매체로 탐색한다.
- **[2슬03-01]** 하루의 변화와 사람들이 하루를 살아가는 모습을 탐색한다.
- **[2슬03-02]** 계절과 생활의 관계를 탐구한다.
- **[2슬03-03]** 관심 있는 대상의 과거와 현재를 살펴보고 미래를 상상한다.
- **[2슬03-04]** 우리의 생활과 관련된 지속가능성의 다양한 사례를 찾고 탐색한다.
- **[2슬04-01]** 생활도구의 모양이나 기능을 탐색하고 바꾸어본다.
- **[2슬04-02]** 상상한 것을 다양한 매체와 재료로 구현한다.
- **[2슬04-03]** 경험한 것 중에서 관심 있는 주제를 정하고 조사한다.
- **[2슬04-04]** 배운 것과 배울 것을 연결하며 앞으로의 배움을 상상한다.

> **이것이 "과학"이 들어가는 자리다.** 초1~2에 과학 교과는 없고, 슬기로운 생활이 그 역할을 한다.
> [2슬01-04] 생태 탐구, [2슬03-02] 계절과 생활, [2슬04-01] 생활도구 탐색이 과학의 씨앗이다.

## 3. 현재 Domain 5개의 문제

```
'국어' | '수학' | '영어' | '학교적응' | '예체능'
```

| 문제 | 내용 |
|---|---|
| **과학·탐구가 없다** | 누리과정 자연탐구의 2개 내용범주, 슬기로운 생활 16개가 갈 곳이 없다 |
| **사회·인성이 없다** | 바른 생활 16개, 사회관계 '사회에 관심 가지기'가 갈 곳이 없다 |
| **안전이 없다** | 신체운동·건강 '안전하게 생활하기' 4개가 갈 곳이 없다 |
| **'학교적응'은 교육과정 용어가 아니다** | 우리 조어다. 실제로는 사회관계 + 바른 생활에 해당한다 |
| **'수학'이 자연탐구를 쪼갠 것** | 원문에서 수학과 과학은 한 영역(자연탐구)이다 |

**결론: Domain 목록이 원문을 덮지 못한다. P-6의 전제가 깨져 있다.**
