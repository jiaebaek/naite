# 12 · 초2 MVP 통과 기준 체크리스트 (테스트 판정용)

> **용도.** T7(묶음)·T8(레인·등원숙제)·T9(온보딩·생활체크) 구현 후, 네가 앱에서 **직접 확인**해 통과/실패를 판정하는 체크리스트. 근거: SSOT §5 · 명세 §06-A/06-B/07-A/08 · docs/10·11.
> **테스트 2케이스:** ⓐ **2018-01생(=초2)** ⓑ **2021-01생(=만 5세, 회귀 확인)**. 각 온보딩부터.

---

## A. 밴드·온보딩 (T5·T9)
- [ ] 2018-01 입력 → "만 8세 / 초2" 류로 산출되고 **초1~2 목표 band**가 뜬다. (만 5세는 취학전 band)
- [ ] 온보딩 학습 입력이 **과목별 카드**(국어→영어→수학→과학)다. 자유 칩 나열 아님.
- [ ] 각 과목 카드: `학원 있어요?` → (있으면) `숙제 있어요?` 토글 → `집에서 하는 것?`.
- [ ] 학원 유형 칩이 **band에 맞게** 뜬다 — 초2=영어학원·수학학원·논술·코딩 등(초등용), 만5세=한글·놀이수학·유아체육 등(유아용). **유아용 칩이 초2에 안 뜬다.**
- [ ] 과목마다 스킵 가능. 아무것도 안 넣어도 통과.
- [ ] 생활 질문(사회·인성·건강)이 **온보딩에 없다**(별도 모듈).

## B. 묶음 단위 (T7)
- [ ] 영역 화면이 **개별 성취기준 100개가 아니라 묶음**으로 뜬다(초2 국어=듣기말하기·읽기·쓰기·한글·문학·매체 6묶음 류).
- [ ] 묶음 탭 → **근거 성취기준(개별 문장)** 이 상세로 보인다.
- [ ] 복잡해 보이지 않는다(영역당 2~6묶음).

## C. 두 레인 (T8)
- [ ] 화면이 **학습(국·영·수·과)** 과 **생활·마음(사회·인성·건강·안전)** 으로 구분된다.
- [ ] 생활·마음 레인이 **빈칸 알람(허니 갭)으로 안 뜬다.** "유치원·일상에서 챙겨지고 있어요" + [생활 체크] 진입만.
- [ ] 학습 커버리지·안도 카운트에 **생활 빈칸이 안 섞인다**(분리 집계).

## D. 등원 / 숙제 구분 (T8)
- [ ] **태권도·수영·미술** 등록 → "**다니면서** 챙겨져요", 오늘 화면에 **숙제 체크 항목이 안 생긴다**(등원 일정만).
- [ ] **한글·수학학원(숙제형)** → "**숙제로** 챙겨져요" + 오늘 화면 **숙제 체크** 뜬다.
- [ ] "숙제 있어요?" 토글로 바꿀 수 있다. 없는 숙제가 자동 생성되지 않는다.

## E. 커버리지 정직성 (T2·T7)
- [ ] 초2 + 태권도 → **예체능 묶음만** 챙김(미술·음악 묶음까지 챙김 처리 안 됨 = 부풀리기 없음).
- [ ] 학원 등록 시 **미리 체크된 묶음 제안** → 부모가 넘겨야 확정. 안 본 건 커버 안 됨.
- [ ] 매핑은 **챙기는 중**만 만든다. 학원 다닌다고 **이룸**으로 안 바뀐다.
- [ ] 한글학원 = "관심/해득 챙기는 중"이지 자동 "이룸(뗐음)" 아님.

## F. 안도-우선 (원칙6)
- [ ] 온보딩 직후 첫 화면이 **"비어있어요"로 시작하지 않는다.** 안도(이미 챙긴 것) 먼저.
- [ ] 안도 카드가 **사교육 기반 톤** — "○○로 이만큼 챙기고 있어요"(학교가 챙김 배지 없음).
- [ ] 공유 카드에 **좌표 코드(N5·3C7 류) 없음**, 나이테 단면이 부드럽다(뾰족한 레이더 아님).

## G. 생활·마음 체크 모듈 (T9 · §06-B)
- [ ] 홈/현황에 "생활·마음 체크해보기" 진입점.
- [ ] 질문 = 관찰형(예/아직/모름), band별(초2=8문항). "테스트" 표현 없음.
- [ ] "예" → 그 묶음 이룸/챙김으로 잔잔히 반영, 결과가 **안도 톤**.
- [ ] "아직/모름"이 갭 알람·죄책감으로 안 뜬다.

## H. 회귀 (만 5세)
- [ ] 2021-01 온보딩 → 유아용 칩 + 취학전 14묶음. 기존 동작 유지, 커버 정상.
