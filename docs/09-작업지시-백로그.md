## T2 · 매핑 신뢰 4속성을 계약+테스트로 (활동→목표)

**맥락:** SSOT §2(신뢰 4속성)·§5(매핑 3필터·부풀리기 가드레일). 활동(예: 태권도)을 목표에 연결할 때 관련성으로 과잉매핑하면 커버리지가 부풀고 신뢰가 깨진다.

**할 것:**
1. **활동유형→후보목표 프리셋 맵** 신설(`src/domain/standards/` 아래). **큐레이션 원본 = [10-프리셋-활동목표-큐레이션.md](10-프리셋-활동목표-큐레이션.md) (전략 산출물 · 완료).** 그 표를 그대로 인코딩한다. 임의로 매핑을 지어내거나 추가하지 말 것. 데이터 형태·영어 예외·가드레일은 그 문서 하단 참고.
2. **부풀리기 탐지 테스트:** 한 활동의 매핑이 **목표 2개 초과** 또는 **영역 2개 이상**에 걸치면 테스트 실패(가드레일 자동화). (부수 opt-in 매핑은 별도 표기로 예외 처리.)
3. **근거 노출:** 매핑에 why/sourceRef 필드 → UI에서 확인 가능(§10-A 카드는 짧게, 상세는 연결 시트).
4. **INV 추가:** "매핑은 '챙기는 중'만 만든다. '이룸'은 만들지 않는다"(2축 불변식). 계약·테스트로.

**수용 기준:**
- 태권도 프리셋 = 예체능 신체활동(`nuri-phy-3`,`nuri-phy-4`) **1영역 2목표**. 인성·규칙은 부수 opt-in.
- 3영역/4목표 매핑 시 테스트가 실패로 잡는다.
- 부모 미확정 제안은 커버리지에 반영되지 않는다(신뢰 속성 ③).
