# 10 · 프리셋 활동유형 → 목표 큐레이션 (전략 산출물)

> **용도.** T2([09-작업지시-백로그.md](09-작업지시-백로그.md))의 "활동유형→후보목표 프리셋 맵"이 인코딩할 **원본 큐레이션.** 학원/활동을 등록할 때 앱이 이 표로 **주 후보목표를 제안**하고 부모가 확인/조정한다.
> **원칙(어기면 안 됨):** [00-전략-원칙.md](00-전략-원칙.md) §2 신뢰 4속성 · §5 매핑 3필터·가드레일.
> - **3필터:** ①주목적 ②직접·관찰가능 ③활동특정성 을 다 통과 = 주 매핑. ①만 = 부수(opt-in).
> - **가드레일:** 주 매핑 = **1영역·목표 ≤2.** 넘으면 관련성 매핑(부풀리기)이다.
> - **챙김만:** 매핑은 '챙기는 중'만 만든다. **'이룸'은 부모의 별도 관찰.**
> - **마케팅 거부:** 학원 홍보문구(인성·두뇌·집중력·창의력…)를 근거로 쓰지 않는다.
> - 목표 id·문장 원천 = `src/domain/standards/child2021.ts`(누리 `nuri-*`). 아이가 취학 전이라 주 매핑은 nuri-\*. 초1~2 후속은 참고.

## 반드시 지킬 3가지 (구현 시 주의)

1. **한글 = "관심"이지 "해득" 아님.** 누리 원문은 "읽는다"가 아니라 **"읽기에 관심을 가진다"(`nuri-com-8`)**. 한글학원을 다녀도 매핑은 관심 목표에 **챙기는 중**만. "한글 뗐다(이룸)"는 부모가 따로 표시. 해득 자체는 초1 `2국04-01`(입학 후).

2. **영어 = 공교육 0매핑.** 초3 시작이라 취학 전 기준 없음(`NO_PUBLIC_STANDARD`). 프리셋은 영어를 **자체목표(부모 입력 customGoals)로만** 연결하도록 안내. nuri/std에 자동으로 붙이면 안 됨(가짜 근거).

3. **사고력수학 vs 연산.** 팩토류(사고력)=규칙·공간·분류. 취학 전 누리엔 **연산 항목이 없다** — 연산형 학원이라도 매핑은 수량(`nuri-nat-5`)·규칙 선. 등록 시 "사고력형/연산형" 확인 분기 권장.

## 데이터 형태 (T2 인코딩 참고)

```ts
// 활동유형 프리셋 — 주 매핑만 자동 제안. 부수는 opt-in.
interface ActivityPreset {
  readonly type: string            // '태권도' | '미술' | ...
  readonly domain: Domain          // 주 영역
  readonly primary: readonly StandardId[]      // 취학 전(nuri-*) 자동 제안 — band별 ≤2·1영역
  readonly primaryElem?: readonly StandardId[] // 초1~2(std-*) — 확장(현재 대부분 미큐레이션)
  readonly secondary?: readonly StandardId[]   // opt-in, 기본 미선택
  readonly why: string             // 왜 이 활동이 이 목표를 겨냥하나(짧은 한 줄). 연결 시트 노출(신뢰 ②)
  readonly reject?: readonly string[]          // 오버클레임 문구(참고·경고용)
  readonly note?: string           // 한글/영어/수학 분기 주의
}
// ⚠️ 목표 자체의 공교육 근거(누리/성취기준 배지)는 Standard.provenance 가 제공 → 프리셋에 sourceRef 불필요. 프리셋은 why(매핑 이유)만 더한다.
// ⚠️ 영어: primary = [] (공교육 매핑 없음). UI 는 '자체목표로 연결' 경로만 제시.
```

## 초1~2 `primaryElem` 큐레이션 (std-*) — 2026-09 추가

초2까지 MVP 테스트 위해 초1~2 band 매핑을 채운다. 같은 3필터·가드레일(band별 1영역·≤2). 목표 원천 = child2021.ts 초1~2 성취기준.

| 활동유형 | primaryElem (std-*) | why |
|---|---|---|
| 태권도 · 유아체육 · 축구 · 수영 | `std-2즐01-02` | 놀이하며 내 몸의 움직임·감각을 느낀다 |
| 발레 | `std-2즐01-02` · `std-2즐04-03` | 몸 움직임 + 생각·느낌 살려 표현 |
| 미술 | `std-2즐04-03` | 생각·느낌을 살려 전시·표현 |
| 피아노 | `std-2즐02-01` | 참여할 수 있는 문화 예술을 향유(연주) |
| 한글 | `std-2국04-01` · `std-2국02-01` | 자모 소릿값·쓰기 + 글자·단어·문장 소리내어 읽기 (한글학원 주목적) |
| 사고력수학 | `std-2수02-01` · `std-2수03-03` | 규칙 찾아 표현 + 평면도형 이해 |
| 독서 | `std-2국02-05` · `std-2국05-04` | 읽기에 흥미·즐겨 읽기 + 시·이야기에 흥미 |
| 영어 | `[]` | 초3 시작, 공교육 매핑 없음(유지) |

> 한글: 초1~2에선 자모·읽기를 학원이 실제로 겨냥하므로 `2국04-01`·`2국02-01` 매핑이 정직하다(취학 전 "관심"과 달리). 단 여전히 **챙기는 중**만 만든다(해득=이룸은 부모 확인).
> 사고력수학: 연산형이면 `std-2수01-*`이나, "사고력" 타입은 규칙·도형. 학원 성격 다르면 조정.
> 피아노: `2즐02-01`은 다소 넓음(악기 연주 특정 std 없음) — 과소청구 원칙상 borderline, 필요시 비움 가능.

**band 처리(Q3):** 엔진은 아이 현재 band 것만 적용·카운트한다(취학 전=`primary`/nuri-*, 초1~2=`primaryElem`/std-*). **MVP는 취학 전(nuri-*)만** 큐레이션 완료 — ICP가 만 5세이기 때문. 초1~2 std-* 큐레이션은 확장 과제. 현재 band에 매칭이 없으면 **제안하지 않는다**(원칙3, 억지 매핑 금지).

**가드레일 테스트(T2):** `primary`·`primaryElem` 각각 `length <= 2` 그리고 단일 domain(= band별 검사). 위반 시 실패.

## 매핑 확정 → 커버리지 배선 (결정 2026-09)

**"학원 넣으면 그 영역 전체 챙김"은 폐기.** 영역-whole 자동커버는 오버클레임(신뢰① 위반: 태권도로 예체능 전부 챙김은 거짓). 활동은 **프리셋이 제안한 특정 목표만** 챙긴다.

1. 활동 등록(셋업 §06-A / 활동 연결 시트 §10) 시 프리셋이 `primary` 목표(1~2)를 **미리 체크된 제안**으로 띄운다.
2. 부모가 **원터치 확인(수정 가능)** → 그 목표만 `챙기는 중`. `secondary`는 미선택 opt-in.
3. **미확정(부모가 못 보고 지나침)은 커버리지 미반영**(신뢰③). pre-checked 상태를 저장/계속으로 넘기면 = 봤고 끌 수 있었으니 확정으로 간주.
4. 커버리지 변화 = 확인된 목표만 `비어있음 → 챙기는 중`. **이룸은 별도 축**(활동은 이룸을 만들지 않음, 신뢰 §2).
