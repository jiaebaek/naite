나이테 · 리디자인 draft 1.1

“오늘 뭘 해야 하지?”와 “놓친 건 없나?”를 첫 화면에서 동시에

원래 앱은 첫 화면을 펫 키우기가 차지하고, 정작 핵심 가치인 ‘지금 나이에 비어있는 영역’은 두 번째 탭에 숨어 있었어요. 이 리디자인은 그 순서를 뒤집습니다 — 매일 여는 화면이 곧바로 안심시켜 주거나, 채울 곳을 알려주도록.

01

첫 화면에 현황 배너 — 안도 먼저 (1.1 ①)

맨 위에서 “벌써 5곳을 챙기고 있어요”로 안도부터. 갭은 “2곳만 더 보면” 하고 넌지시 + 더 볼 곳 칩. 판단받는 느낌으로 문을 열지 않아요(리퍼럴 생사).

이전 → 비어있는 영역이 오늘 화면에 전혀 안 보였음

02

정체성 한 줄 + 오늘 총 진행

헤더에 “나이에 맞게, 놓치지 않게”를 고정해 뭐하는 앱인지 즉시 전달하고, 할 일에 ‘0 / 6’ 총합을 붙였어요.

이전 → 이름만 있고 설명 없음, 진행은 카드마다 흩어져 있었음

03

선행(先行) 기능 제거

“1년/2년 선행” 잠금 버튼을 뺐어요. 가치는 앞서가기가 아니라 뒤쳐지지 않기니까요. 대신 ‘비어있는 곳 채우기’가 기본 액션입니다.

이전 → 가장 강한 버튼이 검은색 ‘1년 선행’이라 철학과 충돌

04

영역 = 비어있는 곳부터 위로

“먼저 챙기면 좋아요 → 채우는 중 → 다 챙기고 있어요” 순으로 정렬해, 주의가 필요한 것이 항상 맨 위에 옵니다.

05

펫은 하단 보상으로 강등 · 기록은 ‘나이테’로

펫은 슬림한 진행 막대로 축소해 동기부여는 유지하되 자리를 비켰고, 기록 탭은 앱 이름 그대로 겹겹이 쌓이는 나이테 링으로 표현했어요.

06

첫 방문 온보딩 3장

한 장에 개념 하나 — ①정체성(나이테·앞서가지 않아도 괜찮아요) → ②이 앱만의 방식(공교육 기준으로 비어있는 곳 찾기) → ③매일의 루프(체크하면 한 겹씩). 앱을 열자마자 “뭐하는 앱, 어떻게 쓰는지”가 심어져요.

이전 → 온보딩이 아예 없어 곧장 데이터로 떨어졌음

07

영역 상세 = 목표 단위의 갭

영역 카드의 버튼을 누르면 성취기준 하나하나로 쪼갠 상세가 열려요. 비어있는 목표를 위로, 각 목표엔 추천 활동과 ‘활동 연결’ / ‘이미 해요’ 두 갈래를 뒀습니다 — 학원 활동으로 채우거나, 아이가 이미 하는 건 바로 챙김 처리.

데모에선 영역 탭의 어느 카드를 눌러도 ‘국어’ 상세로 이어집니다

08

활동 연결 = 갭 루프의 종착점

상세에서 ‘활동 연결’을 누르면 바텀시트가 올라와요. 추천 활동 원터치 / 기존 학원 숙제에 연결 / 새 활동 직접 만들기 세 갈래. 연결하면 커버리지 바가 실제로 차오르고 그 목표가 ‘챙기는 중’으로 이동합니다. ‘이미 해요’는 활동 없이 바로 챙김 처리.

상세에서 국어의 아무 ‘활동 연결/이미 해요’나 눌러 직접 확인해 보세요

09

관리 = 설정 + 데이터 + 성취 됨-처리

헤더 기어로 진입. 아이 정보(시기 기준) · 학원(등원 알림 소스) · 활동 · 성취 됨-처리(이미 하는 목표를 일괄 챙김) · 기타. 원래 앱의 ‘성취 기록’을 흡수하되 선행 잠금 언급 카피는 제거했어요.

헤더 기어(⚙)를 눌러 확인 · ‘됨으로’ 토글로 gap을 바로 정리

10

기록 · 주간 목표 달성 + 지난 날 채우기

활동마다 주간 목표 횟수 대비 달성을 pip으로 보여줘요(주1회는 한 번 하면 완료). 이번 주 스트립의 지난 날짜를 탭하면 그 날 체크시트가 열려 소급 기록 → 도트·주간 달성이 즉시 갱신. 미래 날짜는 비활성.

기록 탭에서 지난 날(월·화·수)을 눌러보세요 · 되살린 두 기능

11

학원 · 활동 추가/편집 폼

관리에서 추가/편집을 누르면 바텀시트 폼이 올라와요. 학원: 이름·요일칩·시간·연락처. 활동: 이름·소속(학원↔학원선택/자체/자유)·주간 목표 스텝퍼·겨냥 목표 연결. 편집은 기존 값이 채워지고 삭제 버튼이 붙어요.

관리(⚙)에서 ‘활동 추가’·각 행 ‘편집’을 눌러보세요

12

상태 모델 정정 — 챙김 ≠ 이룸 (2축)

‘활동 연결(챙기는 중)’과 ‘됨(이룸·달성)’은 다른 축이라 공존한다. 활동으로 챙기던 목표도 아이가 해내면 이뤘어요로 표시 — 비어있음 → 챙기는 중 → 이룸의 흐름. gap은 ‘활동도 없고 이룸도 아닌’ 것만.

영역 상세에서 ‘이뤘어요’·‘이룸 해제’, 관리에서 활동 연결된 목표의 ‘됨’ 토글을 확인하세요

13

첫 실행 셋업 — 아이 정보 + 내 학원 (1.1 ③)

온보딩 직후 2스텝. 생년월(좌표 기준)과 다니는 학원 하나를 첫 흐름에서 받아요. 학부모가 넣은 학원 = 향후 학원 확보(B2B2C)의 쐐기라, 관리에 묻지 않고 승격.

온보딩 마지막 ‘시작하기’ 다음에 이어져요 (온보딩 다시 보기로 확인)

14

안도 공유 카드 — 나이테 좌표 데이터-아트 (1.1 ④)

오늘 배너의 ‘우리 아이 좌표 공유하기’ → 아이마다 실루엣이 다른 유기적 좌표 이미지(7영역 방사형 블롭 + 나이테 결 + 상태 점). 링+숫자로는 안 퍼져요 — ‘나만의 좌표’라야 스샷·공유됩니다. 자랑 아닌 안도 톤, 이름 기본 가림, 링크는 무료 갭 진단으로 → 리퍼럴 루프.

오늘 화면 배너 아래 ‘우리 아이 좌표 공유하기’를 눌러보세요

팔레트 : 딥 파인그린(신뢰·정체성) + 허니 앰버(비어있음 — 경고 빨강 대신 “채우면 좋아요”의 따뜻한 톤) + 세이지(챙김).
서체 : 고운바탕(정체성·감성 문구) + 본고딕(UI·데이터).
→ 오늘 할 일을 체크하면 진행·펫이 실제로 반응하고, 갭 배너·탭은 눌러서 이동할 수 있어요.
