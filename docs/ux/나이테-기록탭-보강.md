# 나이테 명세 보강 — 기록 탭 (Addendum 01)

> 이 문서는 이미 전달된 **《나이테 리디자인 설계 명세》 draft 1.0**의 **§11 화면 스펙 · 기록**을 보강합니다. 본문을 대체하지 않으며, 이 문서 내용만 추가로 반영하면 됩니다.

## 배경

리디자인 초안에서 기록 탭을 단순화하는 과정에, 원본 앱에 있던 두 기능이 **누락**됐습니다. 둘 다 실사용상·철학상 필요하여 되살립니다.

1. **주간 목표 달성 표시** — "주 N회" 목표를 채우면 완료로 보이던 것 (예: 주1회 활동은 한 번 하면 완료).
2. **지난 날 기록 추가(backfill)** — 지난 날짜를 눌러 소급으로 채우던 것.

---

## A. 주간 목표 달성 표시

### 개념

활동(Activity)은 **주간 목표 횟수**(`weeklyTarget`)를 가진다. 기록 탭의 활동별 현황은 단순 횟수가 아니라 **목표 대비 달성**으로 표기한다. 앱 전체의 pip(작은 칸) 언어를 그대로 사용해 시각 일관성을 유지한다.

### 상태 규칙

| 조건 | 표시 | 색 |
|---|---|---|
| `done ≥ target` | **완료** (체크 아이콘 + "완료") | 세이지 `--sage` |
| `0 < done < target` | `{done}/{target}회` | 본문 보조 `--ink-soft` |
| `done = 0` | "이번 주 없음" | 중립 `--muted` |
| `target` 없음(자유 활동) | `{done}회` (또는 "이번 주 없음") | 보조/중립 |

- **pip 행**: 목표 횟수만큼 칸을 두고, 완료한 만큼 세이지로 채운다.
- **미완 칸은 중립 회색**(`--line-strong`)으로 둔다. **허니(gap 색)를 쓰지 않는다** — 허니는 §04의 ‘목표 비어있음’ 전용이며, 주간 미완은 갭이 아니라 진행 중이기 때문(혼동 방지).

### 데이터

- `Activity.weeklyTarget`(정수, 0/미설정이면 목표 없음) 필드 사용.
- 주간 `done` = 이번 주(월~일) 해당 활동의 `Record` 개수 집계.

### 예시 (이번 주)

| 활동 | 목표 | 달성 | 상태 |
|---|---|---|---|
| 팩토 숙제 | 주 2 | 2 | 완료 |
| 수학 보드게임 | 주 1 | 1 | 완료 |
| 한글 학원 숙제 | 주 3 | 2 | 2/3회 |
| 영어 원서 1권 | 주 3 | 2 | 2/3회 |
| 영어 영상 20분 | 주 5 | 3 | 3/5회 |
| 알파짱 워크지 | 자유 | 0 | 이번 주 없음 |

## B. 지난 날 기록 추가 (backfill)

### 동작

- **이번 주 스트립의 날짜를 탭**하면, 그 날짜의 활동 체크시트가 **바텀시트**로 열린다(§10 ‘활동 연결’과 동일한 시트 패턴).
- 활동을 체크/해제하면 그 날짜에 `Record`가 **추가/삭제**된다.
- **과거·오늘 편집 가능**, **미래 날짜는 비활성**(흐리게, 탭 불가).

### 즉시 반영

시트에서 토글하면 아래가 그 자리에서 갱신된다.

- 날짜 도트의 완료 개수 (스트립)
- 상단 "N일 챙김" 요약
- 활동별 주간 목표 달성(pip/완료) — A와 연동

### 카피

- 스트립 아래 안내: **"지난 날을 눌러 채울 수 있어요 · 못 채운 날은 그냥 비어 있을 뿐이에요."**
- 시트 안내: **"한 걸 눌러서 체크해요. 지난 날도 채울 수 있어요."**
- 톤: 못 채운 날을 실패로 규정하지 않는다("그냥 비어 있을 뿐").

### 데이터

- `Record(activityId, date)` 생성/삭제. 별도 신규 엔티티 없음(기존 Record 재사용).

---

## 상호작용 · 동기화

- 오늘 화면에서 할 일 체크 = **오늘 날짜의 Record 생성**. 기록 탭 backfill과 **동일한 Record 소스**를 쓴다.
- 주간 목표 달성, 날짜 도트, 나이테 채움률(§11) 모두 `Record`에서 파생된다 → 어느 화면에서 기록하든 전부 일관되게 갱신.

## 컴포넌트 추가

| 컴포넌트 | 설명 |
|---|---|
| 주간 pip 행 | 목표 횟수 칸. 완료=세이지, 미완=중립 회색. |
| 완료 상태칩 | 체크 아이콘 + "완료"(세이지). |
| 지난 날 바텀시트 | 날짜별 활동 체크 리스트. 활동 연결 시트와 동일 패턴(그랩·백드롭·✕). |

## 카피 가이드 추가 (§14 연장)

| 상황 | 이렇게 (O) | 이렇게 말고 (X) |
|---|---|---|
| 주간 미완 | "2/3회" · "이번 주 없음" | "미달 / 부족 / 실패" |
| 주간 달성 | "완료" | "클리어! / 성공!" |
| 못 채운 날 | "그냥 비어 있을 뿐이에요" | "빠뜨린 날 / 놓친 날" |

## 개발 우선순위 (§16 연장)

| 순위 | 항목 | 이유 |
|---|---|---|
| **P1** | 주간 목표 달성 표시 | Activity에 `weeklyTarget` 필드만 추가, 나머지는 Record 집계. |
| **P1** | 지난 날 backfill 시트 | 기존 Record 재사용. 오늘 체크와 동일 로직의 날짜 지정 버전. |
