# 나이테 컨시어지 MVP 런북 (0단계)

> 목적: **코드를 더 짜기 전에**, 손으로 서비스를 배달해서 사업의 척추가 있는지 확인한다.
> 방식: 카카오톡 100% 수기 · 대상 10명 · 기간 4주.
> 이 단계에서 만드는 건 앱이 아니라 **가설의 생사 판정**이다.

- **버전** v1.0
- **연결 문서** [나이테-리디자인-명세 draft 1.1](나이테-리디자인-명세.md) · [기록탭 보강](나이테-기록탭-보강.md)
- **지도 제작 엔진** `child-education-milestones` 스킬 (누리과정 2019 + 2022 성취기준 원문 근거)

## 00. 이 단계의 한 줄

> **"공교육 기준 지도를 손으로 만들어 워킹맘에게 보여주면, 불안이 아니라 안도를 느끼고 → 다시 찾고 → 자기 학원을 말해주는가?"**

이게 yes면 앱을 만들 가치가 있다. no면 뭘 만들든 헛돈. **판정이 이 런북의 유일한 산출물이다.**

## 01. 검증할 가설 & 죽이는 기준 (먼저 못박기)

n=10은 통계가 아니라 **신호**다. 숫자보다 "왜"가 중요. 단, 결정을 위해 기준선은 둔다.

| # | 가설 | 측정 방법 | 통과 기준 | 실패 시 함의 |
|---|---|---|---|---|
| **H1 (안도)** ★핵심 | 공교육 지도를 보면 불안이 아니라 **안도**를 느낀다 | 지도 보기 **전/후** 불안도 1~5 자가체크 + 첫 반응 관찰 | 전보다 안도 ↑ **≥6명**, 더 불안 **≤2명** | **전체 재검토.** 안도-우선 명제(원칙6)가 틀림. 앱 만들기 중단 |
| **H2 (리텐션)** | 콘텐츠 없이도 다시 찾는다 | 4주간 주간 체크인에 반응/먼저 질문/업데이트 요청 | **≥4명**이 주간 터치 절반 이상에 능동 반응 | 저빈도·고신뢰 포지션 재설계 or 가벼운 콘텐츠 필요 |
| **H3 (학원 쐐기)** ★전략 | 자기 아이 실제 학원·숙제를 순순히 말하고, "숙제가 지도를 자동으로 채운다"에 가치를 느낀다 | 인테이크에서 학원 데이터 제공 여부 + 반응 | 학원 데이터 자발 제공 **≥7명**, 숙제-연결 유용 **≥5명** | B2B2C 학원 pull 모델 위태. 수익구조 재고 |
| **H4 (리퍼럴)** | 안도 카드를 다른 엄마에게 보여주고 싶어한다 | "다른 엄마한테 보여주고 싶어?" + 실제 전달 여부 | 그렇다/실제 전달 **≥4명** | 성장엔진 약함. 획득 채널 재설계 |
| **H5 (존재가치)** | 이게 계속 있었으면 한다 | 마무리 인터뷰 "없어지면 아쉬울까?" | 아쉽다 **≥5명** | 니즈 자체 약함 |

**게이트 규칙:** H1은 **필수 통과**(못 넘으면 나머지 무의미, 즉시 중단·피벗). H3는 전략 핵심(못 넘으면 수익모델 재설계). H2·H4·H5는 방향 조정 신호.

## 02. 대상 선정 (10명)

- **1순위:** 워킹맘 지인. 아이 **만 4~6세**(누리과정 대상 — 지도 엔진이 깨끗이 적용됨). 만 5세 중심으로.
- 다양성 확보: 학원 많이 보내는 엄마 / 거의 안 보내는 엄마 / "잘 모르겠다"는 엄마를 **섞는다.** 안도 반응이 유형별로 다른지 봐야 함.
- **의도적 제외:** 이미 교육 계획이 확실한 상위 열정맘(우리 타깃 아님), 무관심층(테스트 참여 자체를 안 함).
- **편향 인정:** 지인 표본이라 시장 대표성은 없다. 지금은 **시장 크기가 아니라 메커니즘(안도가 일어나는가)** 을 본다. 그걸로 충분.

> 모집은 8명만 확정돼도 시작. 진행하며 2명 보충.

## 03. 진행 구조 (5단계)

```
모집 → 인테이크(+불안 베이스라인) → 지도 수기 제작 → 안도-우선 전달 → 4주 체크인 → 마무리 인터뷰
 D0        D0~D2                    D2~D4          D4~D5        W1~W4          W4
```

### 단계 A. 모집 (카톡 1:1)

> **절대 "우리 앱 좀 봐줘"로 시작하지 말 것.** 도움을 요청받는 프레임이면 솔직한 반응이 안 나온다. "내가 만들어봤는데 너한테 도움 될 것 같아"로.

**모집 멘트 (그대로 써도 됨):**
> "○○야, 나 요즘 아이 교육 챙기는 거 정리하다가, **공교육 기준(누리과정·초등 성취기준)으로 '지금 나이에 뭘 챙기면 되는지' 지도**를 만들어봤어. 너희 △△(만 N세) 것도 만들어서 보여줄까? 5분만 몇 개 물어볼게. 좋고 나쁘고 솔직하게 말해주면 나한테 진짜 도움 돼. 파는 거 아냐 😅"

핵심: ① 공교육 기준 강조(신뢰) ② 무료·개인화 ③ 안 판다 ④ 솔직함 요청.

### 단계 B. 인테이크 (지도 만들기 전 5분 질문 + 불안 베이스라인)

카톡으로 아래를 묻는다. **H1을 위해 "불안 베이스라인"을 지도 보기 전에 반드시 먼저 받는다.**

```
[인테이크 질문]
1. 아이 이름(애칭) / 생년월?
2. 지금 다니는 학원·활동 있어? (이름 / 무슨 요일 / 뭐 배우는지)
3. 집에서 따로 챙기는 거 있어? (한글, 책읽기, 영어영상 등)
4. 요즘 아이 교육에서 제일 신경 쓰이거나 걱정되는 거 하나?
5. (베이스라인) "지금 우리 애 교육, 이 정도면 괜찮나?" 마음 상태를
   1(많이 불안) ~ 5(많이 안심) 중 몇이야?
```

> 4·5번이 H1의 사전값. 지도 전달 후 5번을 다시 물어 전/후를 비교한다.

### 단계 C. 지도 수기 제작 (founder가 손으로)

`child-education-milestones` 스킬로 **아이 나이에 맞는 영역별 목표**를 뽑고, 인테이크의 학원·집활동을 각 목표에 매핑해 **챙김/갭**을 판정한다.

**제작 절차:**
1. 아이 생년월 → 현재 시기 확정 → 7영역별 목표 리스트 확보(스킬).
2. 인테이크 2·3번의 활동을 목표에 연결 → **챙김** 표시.
3. 나머지 → **갭**. 단 급하지 않은 것/자연히 되는 것 구분해서 톤 조절.
4. **총 M곳 중 이미 N곳 챙김** 집계.

> **정직 규칙:** 갭을 부풀리지 않는다(그러면 우리가 죽이려는 불안기계가 됨 = H1 자체를 오염). 있는 그대로. 대부분 아이는 "생각보다 많이 챙기고 있음"으로 나올 것 — 그게 안도의 재료다.

### 단계 D. 안도-우선 전달 (제일 중요한 순간)

**감정 순서 강제(명세 원칙6): 안도 카드 먼저 → 갭은 넌지시.** 카톡으로 아래 **안도 카드**를 이미지 or 텍스트로 보낸다.

```
🌳 나이테 · △△(만 5세 8개월)의 지금 좌표

지금 나이 목표 24곳 중  →  이미 17곳 챙기고 있어요 ✅

잘 챙기는 영역: 국어 · 영어 · 건강안전 · 예체능
살짝 비어있는 곳: 과학·탐구, 사회·인성  (급하지 않아요, 참고만!)

근거: 2019 누리과정 · 2022 초등 성취기준
"앞서가지 않아도, 뒤쳐지지 않게"
```

전달 멘트:
> "△△ 지도 나왔어! **생각보다 이미 많이 챙기고 있더라 (24곳 중 17곳).** 국어·영어 쪽은 아주 잘 가고 있고. 과학탐구랑 사회인성이 살짝 비었는데 이건 급한 거 아니고 집에서 이렇게 하면 돼: (한 줄 제안). 어때, 보니까 마음이 좀 어때?"

전달 직후 **관찰·기록:**
- 첫 반응 원문 그대로 캡처(예: "헐 다행이다" vs "과학은 어떡하지…").
- 그리고 **베이스라인 5번을 다시** 물음: "지금은 1~5 중 몇?"

> **금지:** "이거 앱으로 나오면 쓸래?" 같은 유도 질문. "좋지?" 금지. 중립 유지.

### 단계 E. 4주 체크인 (H2·H3 관찰)

주 1회, 가벼운 카톡. **부담 주지 않기.** 목적은 "먼저 찾는가 / 자기 학원 얘기를 계속 하는가".

| 주 | 체크인 멘트 | 무엇을 본다 |
|---|---|---|
| W1 | "이번 주 △△ 뭐 했어? 지도에 반영해줄게" | 능동 반응? 활동 보고? |
| W2 | "과학탐구 살짝 비었던 거, 혹시 뭐 해봤어? 아님 그대로도 괜찮아" | 갭이 행동으로? 부담됐나? |
| W3 | (아무 업데이트 없이) "요즘 어때? 지도 다시 보고 싶으면 말해" | **먼저 요청하는가**(리텐션 핵심 신호) |
| W4 | "한 달 됐다! 그동안 어땠는지 5분만 얘기해줄 수 있어?" | 마무리 인터뷰로 연결 |

> W3가 리텐션의 진짜 리트머스다. **founder가 안 밀어도 찾으면** H2 강신호.

### 단계 F. 마무리 인터뷰 (5~10분, 카톡 or 통화)

```
1. 한 달 전 지도 받았을 때 기분이 어땠어? 지금은?
2. 그 지도에서 제일 도움된 건? 쓸데없던 건?
3. 이런 게 앱으로 있으면 쓸 것 같아? 언제 열 것 같아?
4. (H3) 만약 △△ 학원 숙제가 자동으로 이 지도에 체크된다면 편할까?
5. (H4) 다른 엄마한테 이 지도 보여주고 싶었어? 실제로 보여준 적 있어?
6. (H5) 이게 없어지면 아쉬울까? 솔직히.
7. 돈 내야 한다면 얼마까지? (참고용, 압박 아님)
```

## 05. 운영 원칙 (컨시어지의 규율)

1. **손으로 한다.** 자동화·코드 추가 금지. 지도는 사람이 만든다. 그래야 제품 결함이 반응을 오염 안 시킴.
2. **팔지 않는다.** 이 단계 목적은 학습이지 전환이 아니다. "쓸래?"보다 "어땠어?".
3. **유도하지 않는다.** "좋지?" 대신 중립 질문. 나쁜 신호를 환영해라 — 지금 알아야 싼값에 안다.
4. **안도 먼저, 항상.** 갭을 첫 마디로 꺼내지 않는다. 부풀리지 않는다(H1 오염 방지).
5. **원문을 남긴다.** 요약하지 말고 참가자 말 그대로 캡처. "헐 다행" 한마디가 데이터다.
6. **부담 최소.** 체크인은 짧게. 부담 주면 씨앗 단계에서 관계까지 잃는다.

## 07. 다음 결정 (게이트 판정 후)

| 결과 | 결정 |
|---|---|
| **H1 통과 + H2/H3 통과** | 척추 확인. → **1단계(무료 갭 진단 훅) + 프로토타입에 §07-A 첫 세션 반영**으로 진행 |
| **H1 통과 + H3 약함** | 니즈는 맞지만 학원 쐐기 위태. → 수익모델(리드젠 vs SaaS) 재설계 후 재검증 |
| **H1 통과 + H2 약함** | 안도는 되나 안 돌아옴. → 저빈도·고신뢰 포지션 or 가벼운 리텐션 훅 설계 |
| **H1 실패** | **중단.** 안도-우선 명제 자체가 틀림. 제품 방향 근본 재고. 코드 만들지 않는다 |

> 컨시어지의 미덕: **틀렸다면 4주와 카톡 몇 개로 알게 된다.** 앱을 다 만든 뒤 아는 것보다 100배 싸다.
