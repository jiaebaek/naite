## 1. 정체성 · 핵심 경험

나이테는 **"지금 우리 아이 어디쯤이고, 다음에 뭘 챙기면 될까?"에 답하는 성장 지도**다. 할 일 목록·발달 진단기가 아니다.

- 감정 순서: **안도 → 발견 → 이해 → 행동.** ("이만큼 잘 하고 있구나" → "지난번보다 이게 달라졌네" → "지금 시기엔 이걸 보면 되는구나" → "그럼 이거 한번 해볼까").
- 부모가 얻는 것 딱 셋: **① 안도 ② 방향 ③ 한 걸음.**
- 매일 쓰는 앱 아님 — **오랜만에 와도 의미 있는 변화(재방문 델타, §11)가 기다리는 앱.**

## 2. UX 원칙 (판단 기준 · 상세 SSOT §4·§5-B)

1. **안도 먼저** — 어떤 화면도 "비어있어요"로 문을 열지 않는다.
2. **좌표(지도)로 읽힐 것** — 할 일 목록 아님.
3. **입력 최소(통찰 먼저)** — 나이+유치원 1탭으로 첫 화면이 이미 안심. 활동 연결은 게이트 아니라 선택.
4. **비교의 방향** — 또래 비교·숫자등급·도달선 ⛔. 자기 프로필(영역 간 균형)·**강점 발견** = 안도 엔진.
5. **고유한 모양** — 아이마다 좌표가 다른 게 당연. 좋고 나쁜 모양·완성형 없음.
6. **겸손 = 정직** — "가볍게 체크, 진단 아니에요." 근거(전문가 기준)는 뒤, 관찰(부모 언어)은 앞.
7. **추천은 Pull·수단** — 부모가 원할 때만, 무료·집 먼저(§15).

## 3. 성장 좌표 모델 (요약 · 데이터는 [14](../14-성장좌표-데이터모델-과학탐구.md))

화면이 다루는 4층: **기준(근거, 뒤) → 관찰 가능한 행동(부모 언어, 앞) → 좌표(지금 모습) → 다음 경험(활동).**
- **GrowthPoint** = 부모가 보는 성장 단위(기존 묶음/cluster 기반). 영역당 2~4개.
- **좌표** = 관찰(Evidence: 부모 관찰+활동+등원+이룸)로 계산한 "지금 이런 모습". 부모 화면엔 **서술**만, 내부 ordinal 비노출.
- **챙김 ≠ 이룸** 유지: 활동 있음=챙기는 중, 이룸=부모 관찰(2축).

## 4. 정보구조 · 네비게이션

하단 3탭 + 1모듈:
| 탭/모듈 | 역할 | 빈도 |
|---|---|---|
| **오늘**(메인) | 한눈에 안심 + 오늘 할 일/등원 | 자주 |
| **영역** | 성장 좌표 조망(2레인·lean) | 가끔·재방문 |
| **기록** | 나이테 링 + 재방문 델타 | 가끔 |
| **관찰 체크**(모듈) | "3분 우리 애 체크" — 좌표 해상도↑ | 반복(리텐션 훅) |

## 5. 디자인 시스템 (요약)

- 색 토큰: `pine`(브랜드·챙김) · `sage`(챙김/완료) · `honey`(비어있음=따뜻한 넛지, 경고색 아님) · `paper/surface` · `ink/muted`. 위험색(red)은 삭제 등 파괴 동작 전용.
- 서체: **Gowun Batang**(감성·안심 문구·브랜드) / **Noto Sans KR**(기능·데이터). 수치 tabular-nums.
- 라이트/다크 토큰. `prefers-reduced-motion` 존중.

## 6. 온보딩 · 첫 실행 (통찰 먼저 · 입력 최소)

온보딩 3장(정체성/좌표/일상루프) → **초경량 셋업(2탭)** → **즉시 통찰 메인(§7).**
- **S1 · 아이:** 생년월(필수)+이름(선택) → 나이·band 자동.
- **S2 · "어디 다녀요?"(1탭):** 유치원/어린이집 다님? → **등원 자동커버**(누리 baseline+생활·마음 대부분 "챙기는 중" 자동, §13). 초1~2면 "학교 다녀요?".
- 학습 학원·집활동은 여기서 **안 받음** → 통찰 화면의 "학원 추가하면 더 정확해져요"로 선택 진입(§13 과목별 카드).
- 온보딩 2장 카피: "지금 어디쯤인지, **전문가가 세운 기준**으로 보여줘요"(‘공교육’ 단어 안 씀, §14).

## 7. 메인(오늘) = 통찰-먼저 한눈에 안심

목업: `mockup-메인-통찰먼저.html`. 위→아래:
1. **앱바:** 나이테 + 태그라인 `나이에 맞게, 놓치지 않게`.
2. **안심 히어로:** 나이테 링(부분참) + 세리프 "이 시기 챙길 것, 대부분 잘 되고 있어요" + `N곳 중 M곳 챙기는 중` + "유치원·일상에서 대부분 챙겨지고 있어요" + 권위 한 줄 "아이 발달·교육 전문가들이 세운 기준으로 정리".
3. **2레인 요약 바:** 학습(국·영·수·과) / 생활·마음(사회·인성·건강·안전) 각 한 줄.
4. **넛지 1개**(급하지 않은 톤).
5. **오늘 할 일·등원**(있을 때). 6. **펫**(하단 슬림).
- "갭 먼저" 금지 — 안도가 문을 연다.

## 8. 영역 = lean (강점 접힘 + 살펴볼 것 · 2레인)

목업: `mockup-영역탭-단순화.html`. **잘한 건 접고, 살펴볼 것만 펼친다**(progressive disclosure).

### 레인 A · 학습 (국·영·수·과)
- 상단: `학습, 대부분 잘 되고 있어요`(말로. 바·숫자 노출 X).
- **잘 챙기는 영역 = 접힌 한 줄:** `✓ 국어·영어·예체능 — 잘 되고 있어요 ›`(탭 시 펼침). 카드로 안 나열.
- **살펴볼 곳 = 1~2개만 카드:** 점선 초대 톤("연산·놀이수학 알려주면 채워져요 · 급하지 않아요") + 액션 하나. 미입력=경보 아니라 초대.
- 제거: pip·커버리지 바·3그룹 정렬·pill 남발(→ 상태는 말로). 바·근거는 상세(§9)로.

### 레인 B · 생활·마음 (사회·인성·건강·안전)
- `유치원·일상에서 챙겨지고 있어요` + [🌱 3분 우리 애 체크](§10). 빈칸 알람 X. 학습 집계와 분리.

## 9. 영역 상세 = GrowthPoint 프로필

영역을 **GrowthPoint 프로필**로. (데이터·과학탐구 예시 [14](../14-성장좌표-데이터모델-과학탐구.md).)
- **요즘 우리 아이 모습:** GrowthPoint별 서술 + 상태색(🟢 앞선 곳 먼저=강점 / 🟡 덜 보임=다음 경험). "이 아이만의 모양 · 좋고 나쁜 모양 없어요" 캡션.
- **다음에 한번:** 다음 경험 1개(활동 Pull, §15).
- **근거는 뒤:** 각 GrowthPoint "왜 이 목표?" 탭 → 성취기준 원문("전문가가 세운 국가 기준"). 원문 그대로(의역 X).
- ⛔ 숫자/단계·또래·도달선 노출 금지.

## 10. 관찰 체크 모듈 ("3분 우리 애 체크")

- 성취기준을 부모 언어로 번안한 **관찰 행동** 질문. **예/아직/모름** 3택. 문항 = [11 §7](../11-묶음-온보딩-큐레이션.md).
- "예"=이룸/좌표 반영. "아직"=넛지 없이. "모름"=미표시.
- ⚠️ "테스트"·평가·점수 아님. "요즘 이런 모습 하나요?" 톤. "못 하는 게 아니라 아직."
- 결과: 안도("생활·마음도 이만큼")+ 메인 좌표 해상도↑. **재방문 훅.**

## 11. 기록 = 나이테 링 + 재방문 델타

- **나이테 링(히어로):** 바깥=현재 시기(부분참), 안쪽=지난 시기. 중앙 새싹. "한 겹씩 쌓이는 중".
- **재방문 델타(핵심):** 다시 열면 **"지난번보다 달라졌어요"**(새로 나타난 모습·이룸·월령) → "이제 이 시기엔 이걸 볼까요?". = 리텐션 방아쇠(SSOT §8).
- 유치원·일상 자동커버도 이 겹에 쌓임(할일앱으로 안 읽히게).
- "못 채운 날은 그냥 비어 있을 뿐" 톤.

## 12. 공유(안도) 카드

목업: `mockup-화면별-통찰먼저.html` 참조.
- 아이마다 다른 **나이테 좌표(데이터-아트, 부드러운 동심)** = 고유 모양(리퍼럴 훅). `${child}, 만 N세 · N묶음 중 M 챙기는 중`.
- 신뢰 배지 "전문가가 세운 기준으로 정리"(리퍼럴 시 권위 전파). 좌표 코드(암호) 없음.
- 톤: 자랑 아니라 안도. "챙기는 중"만(이룸과 분리). 이름 기본 가림. 공유 링크 → 무료 진단 랜딩(GTM §7).

## 13. 관리 · 학원/활동 (등원 vs 숙제)

- **아이 정보**(생년월) · **학원**(등원처) · **활동** · **관찰 기록**.
- **등원 커버 vs 숙제 커버 구분**(SSOT §5): 등원형(태권도·수영·미술…)="다니면서 챙겨져요"·오늘 화면 일정만 / 숙제형(한글·수학·논술)="숙제로 챙겨져요"·오늘 체크. 기본값=활동유형, "숙제 있어요?" 토글.
- 활동→GrowthPoint 매핑 = 프리셋([10](../10-프리셋-활동목표-큐레이션.md)) primary 미리체크 → 부모 확인(신뢰③). 과잉매핑 금지(가드레일).

## 14. 카피 · 보이스

| 상황 | 이렇게 (O) | 이렇게 말고 (X) |
|---|---|---|
| 비어있음/덜 보임 | "아직 덜 보여요 · 채우면 좋아요" | 누락/미달/부족 |
| 권위 | **"전문가가 세운 기준"** | "공교육"(화면 노출 금지) |
| 상태 | "궁금하면 직접 알아봐요"(서술) | "Level 3 / 3단계" |
| 비교 | (자기 프로필만) | "또래보다 / 상위 N% / 정상·지연" |
| 관찰 | "요즘 이런 모습 하나요?" | "테스트 / 평가 / 진단" |

> UI 카피 규칙: **화면엔 "공교육" 안 씀 → "전문가가 세운 기준"**, 배지는 표준 이름(`누리과정`/`성취기준`). 내부 데이터·코드는 그대로(SSOT 원칙3).
