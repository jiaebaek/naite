## 01. 배경과 문제 정의

기존 앱은 필요한 데이터와 로직은 갖췄으나, 핵심 가치가 첫 화면에서 보이지 않아 "그냥 할 일 + 펫 앱"처럼 읽혔습니다.

### 이 앱이 존재하는 이유 (핵심 가치)

부모의 니즈는 **성취(잘하게 만들기)가 아니라 챙김(놓치지 않기)** 입니다. "앞서가진 않더라도 뒤쳐지진 말자" — 지금 나이에 챙겨야 할 것 중 **비어있는 것(gap)을 찾아 메우는 것**이 제품의 존재 이유입니다. 성취·순위·선행이 아닙니다.

### 진단된 문제

1. **첫인상 실종** — 앱 이름 외에 "뭐하는 앱인지" 알려주는 요소가 없음. 온보딩 부재.
2. **가치가 2번째 탭에 숨음** — 비어있는 영역(gap)은 `영역` 탭에만 있고, 매일 여는 `오늘` 화면엔 노출되지 않음.
3. **시각적 우선순위 역전** — 첫 화면 상단 40%를 펫(보상 장치)이 차지. 정작 중요한 정보는 아래로 밀림.
4. **철학과 충돌하는 기능** — 각 영역 카드의 가장 강한 CTA가 "1년/2년 선행". 가치(뒤쳐지지 않기)와 정반대.
5. **오늘 진행 파악 불가** — 총합 진행 지표 없이 카드마다 흩어진 `0/N`.

### 리디자인 목표

- 앱을 열면 **3초 안에** "뭐하는 앱 + 지금 놓친 게 있나"가 읽힐 것.
- 매일의 사용은 `오늘` 화면 하나로 끝날 것 (주 사용자는 워킹맘, 학원 숙제 담당).
- "비어있음"을 죄책감이 아니라 **다음 행동**으로 전환할 것.

## 02. 설계 원칙

모든 화면 결정은 아래 5개 원칙에서 파생됩니다. 스펙이 애매할 때 이 원칙으로 판단합니다.

- **원칙 1 — 갭 우선(Gap-first).** 모든 목록은 **비어있는 것 → 채우는 중 → 다 챙김** 순으로 정렬한다. 주의가 필요한 것이 항상 맨 위에 온다.
- **원칙 2 — 매일은 '오늘' 하나로.** 일상 사용에 필요한 모든 것(할 일·놓친 것·등원)을 `오늘`에 모은다. `영역/기록`은 주 1회 점검용.
- **원칙 3 — 공교육 근거를 신뢰 자산으로.** 모든 목표는 출처(**누리과정·성취기준·자체·자유**)를 배지로 노출한다. 이게 경쟁 앱과의 차별점.
- **원칙 4 — 비어있음은 경고가 아니다.** gap은 빨강(에러)이 아닌 **허니 앰버(따뜻한 넛지)** 로 표현하고, 항상 "채우면 좋아요"로 카피한다. 부담을 주지 않는다.
- **원칙 5 — 앞서가기 기능 없음.** '선행' 개념·UI를 제품에서 제거한다. 목표는 언제나 "현재 시기" 한 겹뿐이다.

## 03. 정보구조 · 네비게이션

하단 3탭 구조는 유지하되, 각 탭의 역할과 진입 흐름을 명확히 한다.

| 탭 | 역할 (한 문장) | 사용 빈도 | 진입 시 기본 |
|---|---|---|---|
| **오늘** | 오늘 할 일 + 지금 놓친 것 + 등원 일정 | 매일 | 앱 실행 기본 화면 |
| **영역** | 7개 발달 영역별 챙김 현황 점검 | 주 1~2회 | 갭 배너 탭 시 여기로 이동 |
| **기록** | 쌓아온 것 돌아보기 (나이테) | 가끔 | — |

### 화면 계층 (drill-down)

`오늘` · `영역` · `기록`은 최상위 탭. 그 아래 **drill-down 화면**:

- `영역` → 영역 카드의 버튼 → **영역 상세** (뒤로가기로 영역 복귀, 탭 하이라이트는 '영역' 유지)
- `영역 상세` → 비어있는 목표의 '활동 연결' → **활동 연결 바텀시트** (모달)
- `헤더 기어` → **관리** (아이 정보·학원·활동·성취 됨-처리 — §12)

첫 실행 시 **온보딩 3장**이 전체 화면 오버레이로 뜨고, 완료/건너뛰기 후 `오늘`로 진입. 재노출은 관리 화면의 항목으로 제공.

## 04. 핵심 개념 · 상태 모델

전 화면이 공유하는 도메인 개념과 상태 정의. 색·카피·정렬이 모두 여기서 나온다.

### 3계층: 영역 → 목표 → 활동

- **영역(Domain)** — 발달·교육 영역. 현재 시기 기준 7개: 국어, 수학, 과학·탐구, 영어, 사회·인성, 예체능, 건강·안전.
- **목표(Milestone)** — 그 시기에 챙길 구체 성취. 출처가 있음(누리과정/성취기준/자체). *예: "자기 이름을 쓴다", "20까지 세고 숫자를 읽는다".*
- **활동(Activity)** — 목표를 챙기는 실제 행위. 학원 숙제이거나(학원 연결) 자체/자유 활동. 하나의 활동이 하나 이상의 목표를 겨냥(cover)한다.

> **두 축 (중요)** — **챙김(활동 연결)** 과 **이룸(됨)** 은 **서로 다른 축**이다. **활동 연결 = 이 목표를 향해 하는 활동이 있다(진행)**. **됨 = 아이가 이 목표를 이루었다(달성·결과)**. 활동으로 챙기던 목표도 아이가 해내면 이룸이 되므로, **됨은 활동 연결과 무관하게 항상 표시할 수 있어야 한다.** (초기 설계가 이 둘을 "챙김" 하나로 뭉갠 것을 정정)

### 목표 상태 (Milestone status) — 2축 → 3상태

| 활동(챙김) | 됨(이룸) | 상태 | 표시 · 색 |
|:---:|:---:|---|---|
| ✗ | ✗ | **비어있음** | 허니 좌측 바 · "아직 챙기는 활동이 없어요" · `--honey-2` |
| ✓ | ✗ | **챙기는 중** | 연세이지 좌측 바 · "{활동}로 챙기는 중" · `sage 55%` |
| ✓ or ✗ | ✓ | **이룸** | 세이지 좌측 바 + 체크 · "이뤘어요" · `--sage` |

- **gap(비어있음)** = 활동도 없고 이룸도 아닌 것만. 핵심 가치 "놓치지 않기"의 대상은 언제나 gap. 흐름은 **비어있음 → 챙기는 중 → 이룸**.

> **상태 전이 규칙(막다른 길 금지)** — 활동 연결은 **챙기는 중**으로, '됨'은 **이룸**으로 만든다. **됨 해제** 시 활동이 남아 있으면 **챙기는 중**, 없으면 **비어있음**으로 되돌아간다 — **토글이 사라져 되돌릴 수 없는 상태를 만들지 않는다.** MilestoneMark는 활동 유무와 독립적으로 저장.

### 영역 상태 (Domain status) — 목표 상태의 집계

| 상태 | 조건 | 정렬 그룹 |
|---|---|---|
| 비어있음 | 영역에 연결된 활동이 0 (목표 전부 gap) | ① 먼저 챙기면 좋아요 |
| 채우는 중 | 일부 목표 챙김, 일부 gap | ② 채우는 중 |
| 완료 | 현재 시기 목표 전부 챙김 | ③ 다 챙기고 있어요 |

### 목표 출처(Source) 배지

| 출처 | 의미 | 배지 스타일 |
|---|---|---|
| `공교육·성취기준` | 2022 개정 교육과정 성취기준 근거 | 파인 톤 (강조) |
| `공교육·누리과정` | 2019 개정 누리과정 근거 | 파인 톤 (강조) |
| `자체 목표` | 공교육 외 부모/제품 설정 목표 | 중립 톤 |
| `자유` | 겨냥 목표 없는 자유 활동 | 점선 중립 |

### 커버리지 지표

영역/상세 상단의 세그먼트 바 = **현재 시기 목표 개수**만큼 칸. **이룸=세이지(진함), 챙기는 중=세이지(연함), 비어있음=허니**. 상세 텍스트 규칙: `목표 {total}곳 · 이룸 {done} · 챙기는 중 {prog} · 비어있음 {gap}곳`. gap=0이면 비어있음 자리를 "비어있음 없음(파인)"으로 대체.

> **중요** — 커버리지는 **"현재 시기" 목표에 대해서만** 계산한다. 미래 시기 목표는 집계·표시하지 않는다(원칙 5). 시기는 아이 생년월 기준으로 산출한다.

토큰 기반. 라이트/다크 동시 지원. 모든 색은 역할 토큰으로만 사용(직접 hex 금지).

| 역할 | 서체 | 용도 |
|---|---|---|

### 핵심 컴포넌트

- **커버리지 바** — n칸 세그먼트(sage/honey). 영역·상세·온보딩 공통.
- **상태 pill** — 비어있음/채우는 중/완료. §04 색 규칙.
- **목표 소스 배지** — §04. 우상단, 강조.
- **할 일 카드** — 체크박스 + 이름 + 소스 배지 + 겨냥 목표 1줄. 완료 시 좌측 바 sage + 취소선.
- **목표 카드(상세)** — 좌측 바 색으로 상태 표현 + 추천 활동 + 액션 2버튼.
- **바텀시트** — 하단 슬라이드업, 백드롭 딤, 라디오 리스트 + 하단 고정 CTA.
- **나이테 링** — 동심원 SVG. 기록/온보딩. 바깥=현재 시기(부분 채움), 안쪽=지난 시기.

모션: `prefers-reduced-motion` 존중. 시트 슬라이드업·펫 게이지·링 채움에만 절제해서 사용.

## 06. 화면 스펙 · 온보딩 (첫 방문 3장)

전체 화면 오버레이. 한 장에 개념 하나. 페이지 인디케이터 + 다음/시작하기 + 건너뛰기.

| 장 | 목적 | 비주얼 | 헤드라인 / 서브카피 |
|---|---|---|---|
| 1 | 정체성·철학 | 나이테 링 (바깥 겹에 허니 점) | "아이의 나이테를 함께 쌓아요" / "앞서가지 않아도, 뒤쳐지지 않게 — 매년 한 겹씩이면 충분해요." |
| 2 | 차별점(갭 찾기) | 커버리지 바 + 영역 목록(챙김/비어있음) | "무엇이 비어있는지 찾아드려요" / "누리과정·성취기준에 맞춰, 비어있는 곳을 콕 집어줘요." |
| 3 | 일상 루프 | 체크된 할 일 → ↓ → 차오르는 링 | "오늘 하나씩, 한 겹씩" / "매일 '오늘' 화면만 열면 돼요." |

| trigger | 동작 |
|---|---|
| trigger | 첫 실행 (온보딩 미완료 플래그) |
| 다음 / 시작하기 | 인덱스 +1, 마지막 장에서는 오버레이 닫고 `오늘`로 진입, 완료 플래그 저장 |
| 건너뛰기 | 즉시 닫고 `오늘` 진입, 완료 플래그 저장 |
| 재노출 | 관리 화면의 '온보딩 다시 보기' 항목 |

> **카피 원칙** — 마지막 장은 기능 나열이 아니라 **"이것만 하면 된다"는 안심**으로 끝낸다. 시작 전에 부담을 주지 않는다.

## 07. 화면 스펙 · 오늘

기본 화면. 위에서 아래로: 정체성 → 갭 배너 → 오늘 할 일(+등원) → 펫(보상).

### 레이아웃 순서 (위→아래)

1. **앱바(고정)** — 로고 + "나이테" + 기어. 하단에 태그라인 `나이에 맞게, 놓치지 않게` 고정 노출.
2. **날짜/나이** — `9월 3일 목요일 · 만 5세 8개월`.
3. **갭 배너** — 이 화면의 핵심. 아래 상세.
4. **오늘 할 일** — 섹션 헤더에 총 진행 `{done} / {total}`. 등원 일정 스트립 → 과목별 그룹 → 할 일 카드.
5. **펫(강등)** — 하단 슬림 카드. 진행 게이지 + 격려 1줄.

### 갭 배너 (신규, 최우선)

- gap이 있을 때: 배경 허니 그라데이션. 헤드(세리프) `지금 {n}곳이 비어있어요`, 서브 `{total}개 영역 중 {on}곳은 잘 챙기고 있어요`.
- 비어있는 영역명을 **칩**으로 나열(예: 과학·탐구, 사회·인성).
- 커버리지 바 + 기본 CTA `비어있는 곳 채우러 가기 →` → `영역` 탭 이동.
- **gap=0일 때(clear 상태)**: 배경 파인 톤, 헤드 `지금은 놓친 곳이 없어요` 류로 전환. 칩·CTA 숨김. (안심 상태도 반드시 설계할 것.)

### 할 일 카드

| 항목 | 스펙 |
|---|---|
| 구성 | 체크박스 · 이름 · 소스 배지(우상단) · `겨냥 {목표}` 1줄. 자유 활동은 `겨냥 목표 없음`. |
| 체크 시 | 완료 스타일(좌측 바 sage+취소선) · 총 진행 +1 · 펫 게이지 갱신 · (기록에 오늘 완료로 반영) |
| 등원 스트립 | 오늘 학원 일정을 시간순 칩으로 표시(일정만, 체크 대상 아님). 학원 엔티티에서 파생. |

> **데이터 주의** — 등원 일정은 학원 엔티티의 스케줄에서, 할 일은 활동에서 온다. 둘은 별개 소스이며 한 화면에 병치될 뿐 섞이지 않는다.

## 08. 화면 스펙 · 영역

현재 시기 7개 영역의 챙김 현황. gap 우선 정렬(원칙 1). 선행 UI 없음(원칙 5).

### 상단 요약

`7개 영역 중 {on}개 챙김 · {gap}곳 비어있음` + 전체 커버리지 바 + 범례(챙기는 중/비어있음/아직 목표 아님).

### 그룹 & 정렬

1. **먼저 챙기면 좋아요** — 비어있음 영역 (활동 0). 예: 과학·탐구, 사회·인성.
2. **채우는 중** — 부분 챙김. 예: 국어(1/6), 수학(2/6).
3. **다 챙기고 있어요** — 완료. 예: 영어(2/2), 예체능(2/2), 건강·안전(3/3).

### 영역 카드

| 항목 | 스펙 |
|---|---|
| 구성 | 이름 · 상태 pill · 목표 단위 커버리지 바(pip) · 상태 문구 |
| 비어있음 | 문구 `지금 시기 목표 {n}곳이 비어있어요 · 활동이 아직 없어요` · 버튼 [활동 추가][목표 N개 보기] |
| 채우는 중 | 문구 `목표 {total}곳 중 {on}곳 챙김 · {gap}곳 남음` · 버튼 [비어있는 목표 채우기][자세히] |
| 완료 | 문구 `목표 {total}곳 모두 챙기는 중` · 버튼 없음(또는 [자세히]만) |
| 버튼 탭 | 해당 영역의 **영역 상세**로 이동 |

> **제거** — 기존의 **1년/2년 선행 세그먼트·잠금(🔒)·"N개 더 하면 열려요"** 는 전부 삭제한다. 공교육 기준이 없는 영역(예: 영어)에는 `공교육 기준이 없어 선행 개념이 없어요`만 표기.

## 09. 화면 스펙 · 영역 상세

영역을 목표(성취기준) 단위로 분해. 비어있는 목표를 위로. 2축 3상태(§04).

### 구성

- **서브바** — 뒤로가기 + 영역명 + 상태 pill.
- **요약 카드** — `목표 {total}곳 · 이룸 {done} · 챙기는 중 {prog} · 비어있음 {gap}곳` + 목표 단위 커버리지 바(3색).
- **그룹 1 · 채우면 좋아요 ({gap}곳)** — 비어있는 목표 (위).
- **그룹 2 · 챙기는 중 ({prog}곳)** — 활동 연결됐으나 아직 이룸 아님.
- **그룹 3 · 이룸 ({done}곳)** — 달성한 목표 (활동 유무 무관).

### 목표 카드 (3상태)

| 상태 / 액션 | 스펙 |
|---|---|
| 비어있음 | 소스 배지 · `아직 챙기는 활동이 없어요` · **추천 활동** 1줄 · 액션 **[활동 연결] [이뤘어요]** |
| 챙기는 중 | 소스 배지 · `{활동명}로 챙기는 중` + 최근 기록 · 액션 **[이뤘어요]** (활동 중이어도 달성 표시 가능) |
| 이룸 | 소스 배지 · `이뤘어요` ✓ + 부제(`활동으로 이룸` / `직접 확인함`) · 액션 **[이룸 해제]** |
| [활동 연결] | 활동 연결 바텀시트(§10). 연결 시 → **챙기는 중** |
| [이뤘어요] | **됨(이룸)** 마크. 비어있음·챙기는 중 어디서나 가능 → **이룸** |
| [이룸 해제] | 활동 있으면 **챙기는 중**, 없으면 **비어있음**으로 되돌림(막다른 길 없음) |

> **즉각 피드백(필수)** — 전이 시 해당 목표가 알맞은 그룹으로 이동하고, 커버리지 바(3색)·카운트·요약이 **그 자리에서** 갱신된다. 비어있음이 0이 되면 요약은 "비어있음 없음"으로.

### 국어 예시 데이터 (만 5세)

목표 6: 자음·모음의 소릿값을 안다(챙김) · 자기 이름을 쓴다 · 받침 없는 단어를 소리 내어 읽는다 · 짧은 문장을 더듬더듬 읽는다 · 책을 읽어주면 끝까지 듣는다 · 간판·과자봉지에서 아는 글자를 찾아낸다 (뒤 5개 gap)

## 10. 화면 스펙 · 활동 연결 (바텀시트)

비어있는 목표에 "무엇으로 챙길지"를 붙이는 모달. 3갈래 단일 선택 + 하단 고정 CTA.

### 구성

- **대상 목표 고정** — 상단에 `{영역} · {목표명}` 항상 노출(무엇을 채우는 중인지 유지).
- **추천 활동** (기본 선택) — 목표별 추천 1개. "새 활동 · 자체 · 주 N회 추천". 원터치 경로.
- **기존 활동에 연결** — 이미 등록된 활동 목록. 학원 활동은 `{학원명} · 주 N회` 부가표시.
- **새 활동 직접 추가** — 점선 행. 선택 시 활동 생성 폼으로(이름·소속 학원/자체·주간 목표 횟수).
- **하단 CTA** — `이 활동으로 연결하기` (sticky).

| trigger | 동작 |
|---|---|
| 열기 | 상세의 [활동 연결]. 선택은 추천으로 초기화. |
| 항목 선택 | 라디오(단일). 선택 항목 파인 보더+틴트. |
| 연결하기 | 목표를 선택 활동에 연결 → 시트 닫힘 → 상세에서 해당 목표 '챙김'으로 전환·이동·커버리지 갱신 |
| 백드롭/✕ | 변경 없이 닫기 |

> **모델 반영** — '기존 활동에 연결'은 **활동↔목표 다대다 매핑** 추가일 뿐 새 활동을 만들지 않는다. 학원 숙제 활동은 `academyId`로 학원과 이미 연결되어 있다.

## 11. 화면 스펙 · 기록

쌓아온 것을 돌아보는 화면. 제품명 그대로 '나이테' 은유를 시각화.

- **나이테 링(히어로)** — 동심원 SVG. 바깥 겹 = 현재 시기(부분 채움, %), 안쪽 = 지난 시기(채워짐). 중앙 새싹. 캡션으로 채움률 설명.
- **이번 주 스트립** — 월~일, 각 날의 완료 개수 도트. 오늘 강조(허니 아웃라인).
- **활동별 이번 주** — 활동명·영역·`{n}회`. 미수행은 `이번 주 없음`(중립).

> **보이스** — "해온 것들을 한 겹씩 쌓아요 / 앞서가지 않아도, 매년 한 겹씩." 성취 압박이 아니라 **축적의 위안**으로 카피한다.

## 12. 화면 스펙 · 관리

헤더 기어로 진입하는 설정·데이터 허브. drill-down(뒤로가기로 오늘 복귀), 하단 탭 하이라이트 없음.

### 섹션 구성 (위→아래)

| 섹션 | 내용 | 비고 |
|---|---|---|
| **아이 정보** | 이름 · 생년월 | 현재 시기·나이 산출 기준(§04·§13). 편집 시 목표 세트가 갱신됨. |
| **학원** | 학원 목록(이름·스케줄·연락처) · [학원 추가] | 오늘 등원 스트립의 소스. 학원=별도 엔티티. |
| **활동** | 활동 목록(이름·소속·주간 목표 횟수·겨냥 목표) · [활동 추가] | 활동↔목표 연결 관리. 학원 활동은 `academyId` 표시. |
| **성취 기록** | 영역별 목표 '됨' 일괄 처리 | 아래 상세. gap 일괄 정리용. |
| **기타** | 온보딩 다시 보기 · 등원 알림 on/off | — |

### 성취 됨-처리 (기존 '성취 기록' 재설계)

영역별 목표 리스트. 각 목표에 **[됨으로] / [됨]** 토글. '됨'은 이 목표를 **이루었다(달성)**는 표시(`MilestoneMark.achieved`). 활동 연결과 **무관하게 항상 토글 가능**.

| trigger | 동작 |
|---|---|
| 열기 | 헤더 기어(⚙) |
| 됨으로 토글 | MilestoneMark on/off → 커버리지·gap·오늘 배너에 즉시 반영 |
| 활동 연결된 목표 | `{활동}로 챙기는 중` 부제 + **됨 토글 그대로 노출**(활동 중이어도 이루면 됨 표시). 토글을 숨기지 않는다 |
| 편집/추가 | 각 엔티티 편집 폼(이름·스케줄·연결 등) |

> **상세와의 관계** — 관리의 '됨' 토글과 영역 상세의 **[이뤘어요]** 는 **동일 데이터**(MilestoneMark = 이룸). 관리 = **초기 셋업·일괄 정리**용, 상세 = **맥락 안에서 단건** 처리용. 즉시 동기화. '됨'은 활동 연결과 독립적으로 항상 켜고 끌 수 있다.

> **카피 변경(필수)** — 기존 문구 **"됨으로 표시하면 그 영역의 선행 잠금이 풀려요"** 는 선행 제거(원칙 5)에 따라 **삭제**. 대신 "챙김으로 처리돼 비어있음으로 뜨지 않아요"로 교체.

### 학원 · 활동 폼 (추가/편집 공용)

관리의 **'추가'·'편집'** 은 바텀시트 폼으로 연다. 활동 연결·지난 날 시트와 동일한 시트 패턴(그랩·백드롭·하단 고정 CTA). **추가/편집은 한 컴포넌트로 겸용** — 제목·초기값·삭제 버튼 유무만 분기한다.

**학원 폼**

| 필드 | 타입 | 비고 |
|---|---|---|
| 이름 | 텍스트 | 필수 |
| 등원 요일 | 요일칩(월~일) 다중선택 | 오늘 화면 등원 스트립의 소스 |
| 등원 시간 | time | — |
| 연락처 | tel | 선택 |

**활동 폼**

| 필드 | 타입 | 비고 |
|---|---|---|
| 이름 | 텍스트 | 필수 |
| 어디서 하나요 | 세그먼트 `학원 / 자체 / 자유` | '학원' 선택 시 아래 학원 드롭다운 노출 |
| 학원 선택 | select(학원 목록) | '학원'일 때만. `academyId`로 연결 |
| 주간 목표 횟수 | 스텝퍼(1~7) | '자유'면 숨김(목표 없음). `weeklyTarget` · 기록 주간 달성(Addendum 01)과 연결 |
| 겨냥 목표 | 성취기준 다중선택 | 활동↔목표 **Coverage 매핑** 생성(§13) |

| trigger | 동작 |
|---|---|
| 열기 | 관리의 [추가](빈 폼) / [편집](기존값 채움 + 삭제 버튼) |
| 저장 | 추가=엔티티 생성, 편집=업데이트. 활동은 Coverage·weeklyTarget 함께 반영 |
| 삭제 | 편집에서만. 이 앱에서 **위험색(red)을 쓰는 유일한 자리**(§05) — 파괴 동작 전용 |

## 13. 데이터 모델 함의

신규 UI가 요구하는 엔티티/관계. 기존 스키마 대비 추가·변경 지점 중심.

| 엔티티 | 핵심 필드 | 비고 / 신규 |
|---|---|---|
| **Child** | 생년월 | 현재 시기·나이 산출의 기준. 온보딩에서 수집 권장(신규 스텝 후보). |
| **Domain** | id, 이름, 시기 | 7개. 시기별 활성 여부. |
| **Milestone** | id, domainId, 문구, `source`, 시기, `recommendedActivity` | `source`=성취기준/누리과정/자체/자유. **추천 활동 텍스트 신규**. |
| **Activity** | id, 이름, `academyId?`, 유형(학원/자체/자유), 주간목표횟수 | 기존. |
| **Academy** | id, 이름, 스케줄, 연락처 | 기존. 등원 스트립은 스케줄에서 파생. |
| **Coverage(link)** | milestoneId × activityId | **다대다 매핑 신규** — '활동 연결'의 저장 대상. |
| **MilestoneMark** | milestoneId, `achieved`(이룸), 확인자 | '됨=이룸(달성)'. **Coverage와 독립** — 활동 연결과 무관하게 저장·토글. |
| **Record** | activityId, 날짜 | 기존. 오늘 체크·주간 집계·나이테 채움률의 원천. |

### 파생 계산

- **목표 상태** (2축) = MilestoneMark.achieved ? **이룸** : (Coverage 존재 ? **챙기는 중** : **비어있음**).
- **gap(비어있음)** = Coverage 없음 **AND** achieved 아님. 오늘 갭 배너·"놓친 곳" 카운트의 대상.
- **영역 커버리지** = 현재 시기 목표 중 챙김 수 / 전체 수.
- **현재 시기** = Child.생년월 → 나이 → 시기 매핑(누리과정/학년군). 미래 시기 목표는 집계 제외.

| 상황 | 이렇게 (O) | 이렇게 말고 (X) |
|---|---|---|
| 비어있는 목표 | "아직 챙기는 활동이 없어요 · 채우면 좋아요" | "누락됨 / 미달성 / 부족" |
| 다 챙긴 상태 | "지금은 놓친 곳이 없어요" | "100% 달성! / 완벽!" |
| 기록 | "한 겹씩 쌓이는 중" | "이만큼 시켰어요 / 진도율" |
| 선행/비교 | (문구 자체를 두지 않음) | "또래보다 앞서요 / 상위 N%" |
| 행동 유도 | 동사 = 결과 그대로 ("연결하기" → "연결됨") | 모호·사과조 |

> **한 줄 원칙** — 숫자로 겁주지 말 것. 항상 **"다음에 뭘 하면 되는지"** 가 함께 보일 것.

## 16. 개발 우선순위

가치 임팩트 대비 구현 비용 기준. P0가 리디자인의 핵심 가치를 전달하는 최소 세트.

| 순위 | 항목 | 이유 |
|---|---|---|
| **P0** | 오늘 화면 갭 배너 + 총 진행 | 핵심 가치를 첫 화면으로. 데이터는 이미 있음(집계만). |
| **P0** | 선행 기능 제거 | 철학 충돌 해소 + UI 단순화. 삭제라 저비용. |
| **P0** | 영역 gap 우선 정렬 + 상태 카피 | 정렬·문구 교체 위주, 저비용 고효과. |
| **P1** | 온보딩 3장 | 신규 유저 이해도. 독립 구현 가능. |
| **P1** | 영역 상세 + 활동 연결 시트 | gap→행동 루프 완성. Coverage 매핑 신규 필요. |
| **P1** | 소스 배지 승격 · 즉각 피드백 | 차별점 가시화 + 완료감. |
| **P1** | 관리 재구성(학원·활동·성취 됨-처리) | 데이터 관리 필수. 성취 됨-처리는 기존 로직 재사용, 선행 카피만 제거. |
| **P2** | 기록 나이테 링 | 정서적 보상. 없어도 핵심 가치엔 지장 없음. |
| **P2** | 온보딩 생년월 입력 스텝 | 시기 산출 자동화(현재 수동 설정이면 후순위). |
| **P2** | 펫 리워크 | 강등만 P0, 애니메이션 고도화는 후순위. |

> **권고** — P0 3종만으로도 "뭐하는 앱 + 오늘 뭐 할지 + 놓친 것"이 즉시 개선된다. 여기부터 배포하고 P1으로 루프를 완성할 것.
