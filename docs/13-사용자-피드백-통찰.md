> **용도.** 챙김 MVP를 지인 부모에게 보여주고 받은 피드백의 종합·결정. 근거: SSOT [00](00-전략-원칙.md). 후속 명세/지시서가 여기서 나온다.

## 2. 핵심 발견

1. **컨셉·이름·나이테 은유는 ICP(불안한 부모)에게 통한다.** C·D 검증. → **포지셔닝 피벗 불필요.** 문제는 가설이 아니라 **전달/실행.** (단 "컨셉 좋다"는 값싼 칭찬 — 낮게 가중.)
2. **문제는 전부 '첫 문(front door)'에 수렴한다.** 복잡·귀찮·입력노동·할일앱 정체성. 원인 = **가치-노동 역전**: "네가 다 입력하면 안도를 보여줄게"가 됐다. 약속("어디쯤인지 우리가 알려준다")과 반대.
3. **신뢰는 '문서'가 아니라 '사람', 특히 교사.** 누구도 "공교육 기준(문서)"을 신뢰 소스로 안 꼽음. D는 "제일 믿는 건 교사". → "공교육이라 전문성 없다"의 뿌리. 실체(누리·성취기준)는 원래 교사·전문가가 만든 것 → **문제는 라벨/전달.**
4. **학원 결정은 로지스틱스가 지배.** 거리·셔틀·라이딩·시간(B·C). 아무도 "발달 커버리지"로 안 고름. → 견적/시간표/셔틀(비용 렌즈)이 실제 결정 도구. 단 커머디티라 훅으로만, 차별화는 챙김+신뢰.
5. **"저학년 때만 되는 것"(시기의 창) = 선행 없는 행동 이유.** D. "지금 아니면 놓치는 것"은 챙김에 urgency를 주는 프레이밍(단 "많이 해두자" 과투자 톤 경계).
6. **입력 자동화 요구.** 유치원/학원 등록하면 자동으로 채워지길. → "입력-0, 통찰-먼저"의 방향과 일치.

## 3. 결정 (이 통찰 → 제품 변경)

- **D1 · 첫 문 역전: 입력-먼저 → 통찰-먼저.** 나이(+유치원 1탭)만으로 첫 화면이 즉시 안심. 활동 연결은 **게이트 아니라 선택적 정교화.** (§06-A 갈아엎음.)
- **D2 · 유치원 등원 자동커버.** 유치원 등록 = 누리 baseline·생활·마음 대부분 "챙기는 중" 자동(SSOT §5 등원커버). 노동 0로 안도.
- **D3 · 한눈에 안심되는 메인.** 100목표·리스트 아님. 한 장 요약(안도 → 2레인 바 → 넛지 1개). (C의 요구.)
- **D4 · 권위를 '사람'으로, 단 정직하게.** "공교육 기준" 라벨은 전문성으로 안 읽힘. 사람-권위(교사/전문가)로 전달하되 **실제 자문이 있기 전엔 "현직교사" 류 문구 금지**(허위 불가). 당분간 benefit/정체성 카피로, **교사 자문 영입 시** 사람-권위 카피로 승격. (권위 카피 = TBD, §명세.)
- **D5 · 비용 렌즈(로지스틱스)는 SSOT §12대로** — 실제 결정 도구임이 재확인. 코어 검증 후 fast-follow.
- **미결(다음 검증):** 불안 ICP가 **새 첫 화면(통찰-먼저)** 에 실제로 안도하는지 — 목업으로 1~2명 더 반응 확인 후 구현.
