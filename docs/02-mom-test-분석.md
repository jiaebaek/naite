## 1. 검증된 고통 (행동 증거 있음 = 진짜)

Mom Test에서 신뢰할 수 있는 건 "그러면 좋겠다"가 아니라 **이미 한 행동**이다.

### P-1. 오늘 할 일이 머릿속에만 있어서 누락된다 ★최상
- 증거: B2 "숙제는 머릿속에 있음"
- 증거: B3 "**어제는 영상은 빼먹었어**" — 인터뷰 대상 기간 안에서 실제 누락 발생
- 증거: B1 "엄마표로 하는 것들은 스스로 인지해야 해서 **가장 까먹기 쉬움**"
- 해석: 학원은 외부 강제력(시간·장소·선생님)이 있어 안 까먹는다.
  **강제력 없는 집 활동만 선택적으로 누락**된다. → 시스템이 대신 강제력이 되어야 한다.

### P-2. 기록이 3중으로 파편화돼 있고 전부 붕괴한다 ★상
- 증거: B2 카톡 / 다이어리 / 냉장고 출력물 동시 사용
- 증거: B2 "어느순간 놓치고 있다는 생각이 들면 **다시** 기록하기 시작함" → 시작·붕괴·재시작 반복
- 증거: C1 노션 이탈, 다이어리 이탈
- 해석: 기록 의지는 충분하다. **도구가 유지에 실패**한다.

### P-3. 시기 판단 기준 부재 → 또래 비교 → 불안 → 충동 지출 ★최상 (가장 비싼 고통)
- 증거: B4 "초등 가기 전까지만 해도 된다고 생각 → 주변 보니 다 읽고 있음 → 늦은건가 → **이번달에 학원 등록**"
- 증거: B4 초등교사 친구에게 질문, AI에게 수학 수준 질문
- 증거: B1 "주변 친구들은 이미 학원을 다 다니고 있었고, **우리 아이만 뒤쳐질까 두려움**"
- **이미 돈이 움직였다.** 지불 의사가 아니라 지불 이력으로 증명된 항목이다.
- 핵심 통찰: 사용자는 "적기교육을 추구한다"고 말하지만,
  **기준이 없어서 실제 의사결정은 또래 비교로 하고 있다.**
  → 시스템의 진짜 가치: 기능 제공이 아니라 **판단 근거를 "주변 친구들" → "공교육 기준"으로 교체**하는 것.

### P-4. 부부간 교육관 불일치로 트러블 ★상 (신규 발견)
- 증거: "엄마 혼자 교육에 대해 알아보다 보니 아빠랑 생각하는 게 달라져서 트러블이 생길 때도 있음"
- 증거: "명확한 기준을 서로 공유하고 싶은 마음도 있음"
- 구조적 원인: **정보 비대칭.** 엄마만 탐색하고 엄마 머릿속에만 결론이 있다.
  아빠는 근거 없이 결론만 통보받는 위치 → 동의하기 어렵다.
- 해석: P-3의 기준표는 불안 해소용이자 **부부 공용 언어**다. 한 산출물이 두 고통을 동시에 친다.
  "내가 이렇게 하고 싶어"가 아니라 "**공교육 기준이 이렇다**"가 되면 논쟁 대상이 바뀐다.
- ⚠️ 주의: 아빠가 그 기준에 **합의한 적이 없으면** 트러블은 그대로다.
  기준표는 통보 도구가 아니라 **합의 도구**로 설계해야 한다.

### P-5. 회사(집 밖)에서 조회·판단해야 한다 ★중
- 증거: B3 "낮에 핸드폰으로 스피킹 관련 정보 검색", "10시쯤 미술학원에 전화해서 시간 변경 문의"
- 증거: D1 "학원에 연락하려면 평일이어야 함" — **학원 영업시간 = 근무시간**. 회사에서 처리할 수밖에 없다.
- 증거: D2 "집에 적어두고 까먹어서 다음날 회사에서 전화하는 걸 깜빡"
- 단, D2 "실제 손해까진 아님" → **P1이지 P0는 아니다.** 웹앱이면 자연히 해결되므로 별도 투자 불필요.
- 부가 요구: "학원에 전화하기" 같은 **처리해야 할 일(Action Item)** 도 관리 대상이다. 숙제만이 아니다.

## 2. 도구 이탈 원인 → 그대로 설계 제약

C1(노션·다이어리 실패)은 요구사항의 원천이다.

| 이탈 원인 | 도출되는 제약 | 검증 방법 |
|---|---|---|
| "모바일에서 쓰기 불편" | **모바일 우선.** 데스크톱은 부차 | 폰에서 한 손 입력 가능한가 |
| "모든 과목을 한눈에 확인하고 싶은데 안 됨" | **전 영역 단일 화면 대시보드.** 탭으로 흩어지면 실패 재현 | 스크롤 없이 오늘 전체가 보이는가 |
| "사용하기 어렵다" | **입력 3초 이내.** 자유 텍스트 최소화, 체크 위주 | 체크 1회로 완료 기록되는가 |
| "다이어리는 집에 있어서 동기화 안 됨" | 회사↔집 동일 상태 | 두 기기에서 같은 화면인가 |

### 진짜 경쟁자는 노션이 아니라 **냉장고에 붙인 A4 한 장**이다
냉장고 종이가 이기는 이유: 열지 않아도 보이고, 로그인이 없고, 0초에 확인된다.
→ **이 시스템은 냉장고 종이보다 쉬워야 채택된다.** 이보다 어려우면 B2의 붕괴 사이클이 반복된다.
→ 특히 **아빠(저관여 사용자)에게는 냉장고 종이가 여전히 최강자**임을 인정하고 설계해야 한다.

| U-2 | 학원 시간 변경이 "자주" 일어난다 (실제 빈도 미확인) | 일정 변경 기능 과설계 |

| U-6 | 아빠가 앱을 최소 1회라도 연다 | 아빠 대상 기능 전부 무효 → 숙제 전달은 계속 구두/카톡 |

## 4. 결론

1. **P-3 + P-4를 하나의 산출물로 친다.** 2021년생 기준표는 앱 없이 문서만으로 즉시 검증 가능하다.
   가장 싼 검증: *"이걸 미리 봤다면 한글 학원 등록 판단이 달라졌겠나?"*, *"이걸 아빠에게 보여주면 대화가 되겠나?"*
2. **P-1이 가장 빈번하다.** 앱의 P0 기능은 여기서 나온다 — 오늘 할 일 + 체크 + 누락 방지.
3. **P-5는 웹앱 선택으로 자동 해결된다.** 별도 우선순위 부여 불필요.
4. **아빠는 사용자로 세되, 기능은 최소로.** U-6가 깨지면 아빠 관련 기능은 전부 매몰비용이다.

## 5. 2차 인터뷰 반영 (2026-08-21, 기준표 검토 후)

기준표를 보여주고 받은 답변으로 아래가 갱신되었다.

### 갱신 1 — P-3의 해법이 "기준 준수"가 아니라 "기준 + 선행 오프셋"으로 바뀜 ★핵심

> "공교육 기준을 명확히 알고 그보다 **1년 정도 미리** 준비하는 게 가장 적절한 것 같다.
>  기준 속도로 갈지, 1년 먼저 갈지, 2년 먼저 갈지 **설정할 수 있으면** 좋겠다."

- 내 초기 해석("기준에 맞추면 불안이 해소된다")은 **절반만 맞았다.**
- 실제 니즈는 **기준을 좌표축으로 삼고, 그 위에서 우리 속도를 스스로 정하는 것**이다.
- 근거: "우리나라에서는 선행교육이 일반화되어 있어서 기준에 딱 맞춰가는 것보다 미리 준비하는 느낌이 좋다"
- → **선행 오프셋(pace offset)이 이 제품의 핵심 차별 기능이 된다.** 단순 체크리스트 앱과 갈리는 지점.
- → 오프셋은 **영역별로 따로** 설정되어야 한다 (한글 1년 / 학교적응 0년 / 영어 측정불가).

### 갱신 2 — P-4(부부 합의) 우선순위 강등 ⬇️

> "아빠에게 **무언가를 요구하는 형태가 되면 안 된다.** 아빠와의 합의는 이 시스템의 **주요 목표가 아니다.**"

- 내가 P-4를 신규 고통 ★상으로 올렸으나, **사용자가 직접 내렸다. 수용한다.**
- P-4는 **목표가 아니라 부수 효과**다. 정보 공유만으로 충분하고, 그 이상은 하지 않는다.
- **강한 제약으로 승격**: 아빠에게 태스크 할당·알림·이행 요구를 하는 기능은 **만들지 않는다.**
  (트러블을 줄이려던 기능이 오히려 트러블 원인이 된다)

### 갱신 3 — U-2 기각. 일정 변경 기능 축소

> "학원 시간 변경은 빈번하지 않다. **2~3개월에 한 번** 정도."

- B1의 "자주 변경됨"은 체감이었고 실제 빈도는 낮다.
- → 변경 이력 관리, 반복 일정 예외 처리 등 **과설계 금지. 단순 수정으로 충분.**

### 갱신 4 — U-6 기각. 아빠용 기능 불필요 확정

> "학원 숙제는 엄마가 말해주는 것 + 학원에서 가져오는 교재 + 아빠가 픽업할 때 듣는 것으로 확인한다."

- 숙제 전달 경로가 **이미 3중으로 작동 중**이다. 앱이 개입할 이유가 없다.
- → **아빠는 사용자가 아니다.** 조회 가능하되 대상으로 설계하지 않는다.
- → 실질 사용자는 **엄마 1명.** 인증·권한·공유 복잡도를 전부 뺄 수 있다.

### 갱신 5 — 기준표에서 가치 있었던 것 (기능으로 확정)

- ✅ **활동을 "공교육 기준 연결 / 초과 목표"로 분류해준 것**
- ✅ **검토 중인 학원에 대한 판단을 제공한 것** (찰리스·에그스쿨·방문영어)
- → 둘 다 앱 기능으로 편입한다.

### 우선순위 최종

| 고통 | 등급 | 비고 |
|---|---|---|
| P-1 할 일 누락 | **P0** | 가장 빈번 |
| P-3 시기 판단 → 선행 오프셋 | **P0** | 가장 비쌈. 핵심 차별점 |
| P-2 기록 파편화 | P1 | P-1 해결의 부산물 |
| P-5 회사에서 조회 | P1 | 웹앱 선택으로 자동 해결 |
| P-4 부부 트러블 | **P3 (비목표)** | 사용자가 직접 강등. 부수 효과로만 |
